## 请按这个顺序审查

### 1. 正确性（最重要）

有没有**能跑通、但某些输入下会错**的情况？具体说：

- **边界值**：输入是 0、负数、最大整数时会怎样？
- **数组越界**：下标会不会超过声明的长度？
- **整数除法**：有没有 `a / b` 两边都是整数，但你以为能得到小数的地方？
- **初始化**：每个变量用之前都赋过值了吗？（C 不初始化就是垃圾值）
- **`scanf` 的 `&`**：每个变量前面都加了吗？（数组名除外）

### 2. 可读性

- 变量名是不是有意义？（`a`、`b`、`t` 只在很短的作用域里可以接受）
- 有没有哪一段逻辑你读了 10 秒还没懂？指出来就行，别重写。

### 3. 冗余

- 有没有重复的判断、可以合并的分支？
- 有没有声明了但没用的变量？

### 4. 符合讲义风格吗

这套讲义里强调过几件事，检查我有没有违反：
- `if` 后面**永远**写花括号（哪怕只有一句）
- 循环上界用 `< n`（从 0 数 n 个）还是 `<= n`（从 1 数到 n），有没有搞混
- 浮点数比较用 `fabs(a - b) < 1e-6`，没有用 `==`

## 输出格式

对每个问题：

```
【严重 / 建议 / 提醒】第 N 行：具体问题
为什么：一句话说明后果
怎么改：只给方向，别给完整代码
```

**如果代码没问题，就直接说"没问题"，不要为了显得有用硬挑毛病。**

最后按严重程度排序：先是**会算错**的，再是**容易误解**的，最后是**风格**的。
