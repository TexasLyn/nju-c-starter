我要在一台电脑上配好 C 语言的学习环境，请你直接帮我做，不要只给我步骤。

## 我的情况

- 操作系统：【Windows 11 / Windows 10 / macOS 版本号，比如 macOS 15】
- 材料的位置：【比如 `C:\Users\me\nju-c-starter` 或 `/Users/me/nju-c-starter`】
- 我之前装过什么：【比如 从没装过 / 装过 Python / 装过 VS Code】
- 我是不是管理员权限：【是 / 不确定】

## 请按这个顺序做，每步都告诉我结果

### 第一步：检查现状，先别动手

依次执行并报告结果：

```bash
clang --version
gcc --version
python3 --version      # Windows 上用：python --version
```

然后告诉我：**哪个已经有、哪个缺、缺的那个要装什么**。

⚠️ **先等我说"继续"再往下做。** 我要先确认你判断得对。

### 第二步：装缺的东西

根据上面的结果：

- **缺编译器**：
  - Windows：用 `winget install -e --id BrechtSanders.WinLibs.POSIX.UCRT`，装完**必须新开一个终端**再验证
  - macOS：`xcode-select --install`（会弹窗，需要我手动点"安装"，你告诉我什么时候点）
- **缺 Python**：
  - Windows：`winget install -e --id Python.Python.3.12`，装完新开终端
  - macOS：一般自带 `python3`；真没有就告诉我用 Homebrew 装
- **都装好了**：跳到第三步

⚠️ 每一步装完都要**在新终端里验证版本号**，别装完就直接宣布成功。

### 第三步：跑通评测脚本

在材料目录下执行：

```bash
python3 tests/check.py --dir answers      # Windows：python tests\check.py --dir answers
```

**期望结果**：结尾输出 `结果：通过 75`。

可能出现的问题，按这个顺序排查：

1. **找不到编译器** → 回第二步
2. **编码错误 / 中文乱码** → Windows 上先执行 `$env:PYTHONUTF8=1` 再跑
3. **某个题目失败** → 把失败的那几题的完整输出给我看，**别自己改代码**，那是材料本身的问题，我需要知道
4. **超时** → 告诉我具体哪一题

### 第四步：验证能编译练习骨架

```bash
python3 tests/check.py --compile-only --dir practice
```

**期望结果**：结尾输出 `结果：通过 71 / 仅编译 4`（那 4 道是故意含错的"找错题"骨架，编译不过是正常的）。

### 第五步：总结给我

用一张表告诉我：

| 项目 | 状态 | 说明 |
|---|---|---|
| 编译器 | ✓/✗ | 版本号 |
| Python | ✓/✗ | 版本号 |
| 评测脚本 | ✓/✗ | 通过多少题 |
| 骨架编译 | ✓/✗ | 通过多少题 |

最后告诉我**下一步我该做什么**（应该是我自己去读 `docs/01-第一个C程序.md` 并开始做题）。

## 几条限制

1. **不要修改 `practice/`、`answers/`、`tests/` 里的任何代码文件**。如果评测不通过，是环境问题，不是代码问题——先诊断，别乱改。
2. **不要装额外的东西**。不要装 CLion、不要装 Xcode 完整版、不要装一堆扩展。只要能编译 + 能跑脚本就够了。
3. **每一步都要我确认**。特别是第一步判完、第二步装之前。
4. **装完新终端才生效这件事，每次都要提醒我。** 这是最容易忘的地方。
5. 如果某一步你**不确定**，告诉我"这步我不确定"，然后给我手动排查的链接，别硬试。
