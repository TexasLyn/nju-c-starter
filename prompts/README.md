# 给 AI 用的提示词

> 这里放的是**写好的提示词**。整段复制，粘到你的 AI 对话框里，然后接着说你的具体问题。

## 怎么用

1. 挑一个下面的文件
2. 打开，**整段复制**
3. 粘到 AI 对话框，把里面的 `【...】` 占位符填掉
4. 发送

## 三条使用原则

**① 每次开新对话都要重新粘贴**

网页版 AI（ChatGPT / Claude / 豆包）**没有记忆**，你关掉窗口它就忘了。所以每次新对话都重新粘一遍。

用 Cursor / ZCode 这类工具的话，可以把这个提示词写进项目根目录的 `AGENTS.md` 或 `.cursorrules`，让它自动生效。

**② 报错和代码要粘文字，不要截图**

AI 读文字比读图片准得多，而且能直接搜关键字。截图里的报错它经常看错行号。

**③ 明确说"不要给我完整答案"**

这些提示词里已经写了这一条，但如果你发现 AI 还是直接给答案了，就再补一句：

> 别给我完整代码，我现在只想知道**下一步该往哪个方向想**。

---

## 这些提示词为什么这么写

不是随便写的，每条规则都对应一个常见问题：

| 提示词里的规则 | 解决的问题 |
|---|---|
| 「先别给完整代码」 | AI 默认会直接给答案，那样你学不到东西 |
| 「报错原文粘给我」 | 没有报错原文，AI 只能瞎猜 |
| 「一次只讲一个点」 | AI 喜欢一口气讲十条，你记不住 |
| 「用这套材料里的术语」 | 避免 AI 用别的教材的概念，和你读的讲义对不上 |
| 「不确定就说不确定」 | C 语言细节多，AI 会编，得让它老实 |
