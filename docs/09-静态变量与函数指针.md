# 09 · 静态变量、全局变量与函数指针

> **本课内容：静态局部变量、全局变量、函数指针、`#ifdef`**
> 两个新东西：**`static` 局部变量**（函数退出后值还在）和**函数指针**（把函数当参数传）。函数指针听起来吓人，其实只是"把函数的名字传进去"。

---

## 1. 复习 `static` 局部变量

第 8 课讲过，这里用例子再过一遍：

```c
#include <stdio.h>

void count_calls(void)
{
    static int n = 0;       /* ← static */
    n++;
    printf("第 %d 次调用\n", n);
}

int main(void)
{
    count_calls();      /* 第 1 次调用 */
    count_calls();      /* 第 2 次调用 */
    count_calls();      /* 第 3 次调用 */
    return 0;
}
```

**两个要点再强调一次**：

1. **`static int n = 0;` 只在第一次进入函数时执行一次。** 之后每次调用都跳过这句，`n` 保留上次的值。
2. **函数返回后 `n` 依然存在**，不像普通局部变量那样消失。

### ⚠️ 常见误解

```c
void f(void)
{
    static int n = 0;
    n = 0;              /* ✗ 如果这么写，static 就白费了 */
    n++;
}
```

**`static int n = 0;` 是初始化，`n = 0;` 是赋值。** 初始化只做一次，赋值每次都做。**想保留值就千万别在函数里再赋一次初值。**

### 用 `static` 变量统计调用次数

```c
int how_many_times(void)
{
    static int cnt = 0;
    cnt++;
    return cnt;
}
```

### ⚠️ 返回 `static` 变量的地址

有一类经典题目：**函数返回局部 `static` 变量的地址。**

```c
int *count(char *ch)
{
    static int n = 0;       /* ← 必须是 static！ */
    n++;
    return &n;              /* 返回它的地址 */
}
```

**为什么必须 `static`？** 如果 `n` 是普通局部变量：

```c
int *bad(void)
{
    int n = 0;              /* ✗ 普通局部变量 */
    return &n;              /* 函数一返回，n 就消失了 */
}
```

函数返回后 `n` 所在的内存已经被回收（可以给别的函数用了）。你拿到的地址指向一块**随时会被覆盖**的内存——这叫**悬空指针**。

**用 `static` 就没问题**：`static` 变量活到程序结束，地址一直有效。

🔸 **记这条规则：要返回指针，指向的东西必须活得比函数长。** 要么是 `static` 变量，要么是全局变量，要么是 `malloc` 出来的（第 13 课）。

## 2. 全局变量：回顾与补充

```c
#include <stdio.h>

double real_part, imag_part;        /* 全局变量，各函数共享 */

void complex_add(double a, double b, double c, double d)
{
    real_part = a + c;              /* 直接写，不用声明 */
    imag_part = b + d;
}

int main(void)
{
    complex_add(1, 2, 3, 4);
    printf("%.1f + %.1fi\n", real_part, imag_part);   /* 4.0 + 6.0i */
    return 0;
}
```

**全局变量的特点**：

- 所有函数都能读写，不用传参
- **自动初始化为 0**（局部变量不初始化是垃圾值）
- 从程序开始活到结束

**什么时候必须用全局变量？** 当你需要**一个函数返回多个结果**，又不想用指针时：

| 方式 | 例子 | 优缺点 |
|---|---|---|
| 全局变量 | `complex_add` 把结果写进全局变量 | 写起来简单，但函数不自包含 |
| 指针参数 | `fun(n, &hw)` | 更规范，但调用时要写 `&` |

**题目说了用哪种就用哪种。** 第 9 课的复数题明确要求"结果存全局变量"，照着做。

## 3. 函数指针：把函数当参数传

### 先看要解决什么问题

假设你要写一个"求定积分"的函数。积分的算法是固定的（分小段累加），但**被积函数 f(x) 是不确定的**——这次可能是 `cos(x)`，下次可能是 `sin(x)`，再下次可能是 `2x+1`。

你希望写成这样：

```c
double integral(double a, double b, int n, ???  f)
{
    /* 这里要用 f 算值，但 f 是什么？ */
}
```

**参数 `f` 应该是什么类型？** 它不是一个数字，是一个**函数**。

答案：**函数指针。**

### 函数指针的写法

```c
double (*f)(double)         /* f 是一个指针，指向"接受 double、返回 double"的函数 */
```

**读法**（从里往外）：

```
double (*f)(double)
        ↑  ↑
        │  └── 这个函数接受一个 double 参数
        └───── f 是一个指针
              f 指向的函数返回 double
```

⚠️ **括号不能省！** 这是最容易写错的地方：

```c
double (*f)(double)     /* ✓ f 是函数指针 */
double *f(double)       /* ✗ 这是"声明一个函数 f，返回 double*" —— 完全不同的东西 */
```

**为什么？** 因为 `()` 的优先级比 `*` 高。`double *f(double)` 会被理解成 `double *(f(double))`，也就是"f 是一个函数，返回 double 指针"。加括号 `(*f)` 才能强制先绑定 `*`。

🔸 **记法：函数指针的名字要和 `*` 一起用括号包起来。**

### 怎么把函数传进去

```c
double f_cos(double x) { return cos(x); }
double f_sin(double x) { return sin(x); }
double f_linear(double x) { return 2 * x + 1; }

/* 积分函数，第四个参数是函数指针 */
double integral(double a, double b, long n, double (*f)(double))
{
    double h = (b - a) / n;
    double s = 0;

    for (long i = 0; i < n; i++) {
        s = s + f(a + (i + 0.5) * h);       /* 像调用普通函数那样用 f */
    }

    return s * h;
}

int main(void)
{
    /* 传函数名的时候【不用写括号，也不用写 &】 */
    printf("%.8f\n", integral(0, 1, 1000, f_cos));
    printf("%.8f\n", integral(0, 1, 1000, f_sin));
    printf("%.8f\n", integral(0, 1, 1000, f_linear));

    return 0;
}
```

🔸 **关键点：传函数名时只写名字，不带括号。**

```c
integral(0, 1, 1000, f_cos)      /* ✓ 传的是函数本身 */
integral(0, 1, 1000, f_cos(1))   /* ✗ 这是"先调用 f_cos(1) 得到结果"，传的是结果 */
```

**带括号就是"调用"，不带括号才是"传这个函数"。** 这是最容易搞混的地方。

### 为什么函数名可以直接传

在 C 里，**函数名本身就代表函数的地址**（就像数组名代表数组首地址）。所以 `f_cos` 和 `&f_cos` 效果一样，写 `f_cos` 更常见。

### 这个模式的价值

**函数指针让"算法"和"具体操作"分开了。** 积分算法只写一次，被积函数想换就换：

```c
/* 同一个 integral 函数，能算各种函数的积分 */
integral(0, 1, 1000, f_cos);
integral(0, 1, 1000, f_sin);
integral(0, 1, 1000, f_linear);
```

**如果要加一个新的被积函数，完全不用改 `integral`。** 这就是"把变化的部分参数化"。

🔸 **这是 C 里"回调"（callback）的雏形**，也是标准库 `qsort` 的核心机制（`qsort` 的最后一个参数就是一个比较函数）。

## 4. `#ifdef` 复习与上机题坑

```c
#define Z

int main(void)
{
#ifdef Z
    printf("Z 被定义了\n");      /* 会输出 */
#else
    printf("Z 没定义\n");
#endif
    return 0;
}
```

**输出 "Z 被定义了"**（因为 `#define Z` 让 Z 被定义过了，虽然它没有值）。

### ⚠️ 上机题最爱考的区别

```c
#define Z 0

#ifdef Z
    printf("A\n");        /* ← 这行会被编译！因为 Z 定义过了 */
#endif

#if Z
    printf("B\n");        /* ← 这行不会，因为 #if 看的是值，Z 的值是 0（假） */
#endif
```

**输出只有 A。**

| 指令 | 检查什么 |
|---|---|
| `#ifdef Z` | Z **有没有被定义**（不看值） |
| `#ifndef Z` | Z **有没有被定义**（反过来） |
| `#if Z` | Z 的**值是不是非 0** |

**一句话记**：`ifdef` 里有个 "d"，是 "defined"（定义过）的意思，所以它只问"定义了吗"。

## 5. 本课最少必要记忆

1. **`static` 局部变量**：只初始化一次，函数退出后值还在
2. **不要在函数里给 `static` 变量再赋初值**，那会抹掉它保留的值
3. **返回指针时，指向的东西必须活得比函数长**（用 `static` 或全局）
4. **函数指针写法**：`double (*f)(double)`，名字和 `*` 要一起加括号
5. **传函数时只写名字，不带括号**；带括号就变成调用了

## 6. 新手最常犯的 3 个错

**① 返回普通局部变量的地址**

```c
int *bad(void)
{
    int n = 5;
    return &n;          /* ✗ n 在函数返回后就没了，返回的地址是悬空的 */
}
```

**症状**：有时候能跑出正确结果，有时候是垃圾值。**这种"时对时错"的 bug 最难查。** 编译器的警告是：

```
warning: address of stack memory associated with local variable 'n' returned
```

**看到 `address of stack memory ... returned` 就一定要改。**

**② 函数指针忘了加括号**

```c
double *f(double)        /* ✗ 这是"函数 f 返回 double*" */
double (*f)(double)      /* ✓ 这是"函数指针 f" */
```

**③ 传函数时带了括号**

```c
integral(0, 1, 1000, f_cos(1.0));    /* ✗ 传的是 f_cos(1.0) 的返回值，是个 double */
integral(0, 1, 1000, f_cos);         /* ✓ 传的是函数本身 */
```

带括号的写法**会报编译错误**（类型不匹配），因为 `double` 不能当函数指针用。这算好事——至少不是静默出错。
