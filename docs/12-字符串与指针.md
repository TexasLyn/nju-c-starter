# 12 · 字符串与指针

> **本课内容：字符串与指针、`string.h`、指针数组**
> 这是指针真正落地的一课。**C 的字符串本质上就是一个字符指针**，把这层想通了，后面结构体和链表就顺了。

---

## 1. 字符串的真相：一个以 `\0` 结尾的字符数组

第 11 课提过一句，现在讲透。

```c
char s[10] = "hello";
```

**这句话在内存里做的事**：

```
   s[0]  s[1]  s[2]  s[3]  s[4]  s[5]  s[6]  s[7]  s[8]  s[9]
  ┌─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┐
  │ 'h' │ 'e' │ 'l' │ 'l' │ 'o' │ '\0'│  ?  │  ?  │  ?  │  ?  │
  └─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┘
                                ↑
                        字符串在这里结束
```

🔸 **`\0`（读作"空字符"，ASCII 值是 0）是 C 用来标记字符串结束的标志。**

**为什么要这个标志？** 因为 C 的字符串**不记录自己的长度**。你只拿到一个"起始地址"，怎么知道到哪结束？靠一路往后找 `\0`。

**这带来三个后果，全都要记住**：

| 后果 | 说明 |
|---|---|
| **`\0` 必须留位置** | `char s[5] = "hello";` 是**错的**，因为要 6 个格子（5 个字符 + `\0`） |
| **长度要自己算** | 想知道多长得用 `strlen(s)` 从头数一遍 |
| **忘了 `\0` 会出事** | 后面所有函数都会一路读到越界 |

### 为什么 `char s[5] = "hello"` 是错的

```c
char a[6] = "hello";      /* ✓ 5 个字符 + 1 个 \0 = 6 */
char b[5] = "hello";      /* ✗ 装不下 \0 */
```

编译器会警告：

```
warning: initializer-string for char array is too long
```

（严格说，C 允许这种写法把 `\0` 丢掉，但那个 `a` 就不再是合法字符串了，后面用 `strlen`、`printf("%s")` 都会读到越界。）

🔸 **习惯：声明字符数组时，长度总是比你要放的字符数多 1。** 或者干脆不写长度，让编译器自己数：

```c
char s[] = "hello";       /* 编译器算出长度是 6 */
```

## 2. 字符串的输入输出

### 输出

```c
char s[] = "hello";

printf("%s\n", s);        /* hello */
printf("%c\n", s[1]);     /* e —— 单个字符用 %c */
puts(s);                  /* hello\n —— puts 自动加换行 */
```

⚠️ **`printf("%s", s)` 和 `printf("%c", s[0])` 的区别**：

```c
printf("%s", s);          /* ✓ 输出整个字符串 */
printf("%s", s[0]);       /* ✗ 灾难！把字符 e（值 101）当地址用 */
```

**`%s` 要的是"地址"，`%c` 要的是"字符值"。** 传错了不会报错，会崩溃或者输出乱码。

### 输入：`%s` 和 `fgets` 的区别

```c
char s[100];

scanf("%s", s);           /* 读到空格就停 */
fgets(s, 100, stdin);     /* 读一整行（含空格） */
```

**⚠️ 注意 `scanf("%s", s)` 里没有 `&`！**

这是第 3 课提到的例外。因为**数组名本身就是地址**，所以不需要再取地址。写了 `&s` 虽然通常也能工作（地址的地址，值一样），但不规范。

| | `scanf("%s", s)` | `fgets(s, n, stdin)` |
|---|---|---|
| 遇到空格 | **停** | 继续读 |
| 能读整行吗 | 不能（只能读一个词） | **能** |
| 末尾的换行 | 不读（留在缓冲区） | **会读进去** |
| 会不会越界 | **会！** 输入太长会溢出 | 不会，最多读 n-1 个字符 |

🔸 **结论：要读一整行（含空格）必须用 `fgets`。**

### ⚠️ `fgets` 会把换行符也读进去

```c
char s[100];
fgets(s, 100, stdin);
/* 你输入 "hello" 按回车，s 里其实是 "hello\n" */
```

**后果**：如果你后面要比较字符串或者输出，会多一个换行。

**去掉它的标准写法**：

```c
s[strcspn(s, "\n")] = '\0';
```

`strcspn(s, "\n")` 返回"`\n` 在 s 里第一次出现的下标"，然后把这个位置改成 `\0`（也就是提前结束字符串）。

⚠️ **如果输入里没有 `\n`（比如输入超长被截断了），`strcspn` 会返回字符串长度**，那时 `s[长度] = '\0'` 是安全的（覆盖了本来就有的 `\0`）。所以这行代码是安全的。

### 教材写法的替换

⚠️ 不少教材和参考答案里用 `gets(s)`。**`gets` 在 macOS 上已经不存在了**（因为不检查长度、极度危险，已被 C 标准删除）。

| 教材写法 | 现代写法 |
|---|---|
| `gets(s);` | `fgets(s, sizeof(s), stdin);` 然后去掉 `\n` |
| `clrscr();`（`conio.h`） | 直接删掉这一行（macOS 没有清屏函数，也不需要） |
| `#include <conio.h>` | 删掉这个 include |

**如果你所在课程要求按教材写法提交**（有些老环境只支持教材写法），**自己在本机练习用上面的替换**。

## 3. `string.h` 常用函数

```c
#include <string.h>
```

必须要这个头文件，否则函数名认不出来。

| 函数 | 作用 | 例子 | 结果 |
|---|---|---|---|
| `strlen(s)` | 字符串长度（**不含 `\0`**） | `strlen("hello")` | `5` |
| `strcpy(d, s)` | 把 s 复制到 d | `strcpy(d, "abc")` | d 变成 "abc" |
| `strncpy(d, s, n)` | 只复制前 n 个字符 | `strncpy(d, "abcdef", 3)` | d 变成 "abc" |
| `strcat(d, s)` | 把 s 接到 d 后面 | d="ab", `strcat(d,"cd")` | d 变成 "abcd" |
| `strcmp(a, b)` | 比较（**字典序**） | `strcmp("a","b")` | 负数 |
| `strncmp(a, b, n)` | 只比较前 n 个字符 | `strncmp("abc","abd",2)` | `0` |
| `strchr(s, c)` | 找字符 c 第一次出现的位置 | `strchr("hello",'l')` | 指向第一个 l |
| `strstr(s, t)` | 找子串 t 第一次出现的位置 | `strstr("hello","ll")` | 指向 "llo" |
| `strcspn(s, t)` | s 开头有多少字符不在 t 里 | `strcspn("ab\n","\n")` | `2` |

### ⚠️ 三个必须记住的点

**① `strlen` 不包含 `\0`**

```c
char s[10] = "hello";
printf("%d\n", strlen(s));        /* 5，不是 6 */
printf("%zu\n", sizeof(s));       /* 10 —— 这是数组的总大小 */
```

**`strlen` 是"字符串有多长"，`sizeof` 是"数组占多少字节"。** 这两个完全不是一回事，上机题爱考。

**② `strcmp` 返回的不是 0/1，而是负数/0/正数**

```c
if (strcmp(a, b) == 0) { /* a 和 b 相等 */ }
if (strcmp(a, b) < 0)  { /* a 在 b 前面（字典序） */ }
if (strcmp(a, b) > 0)  { /* a 在 b 后面 */ }
```

⚠️ **绝对不要写 `if (a == b)` 来比较字符串！**

```c
char a[] = "hello";
char b[] = "hello";
if (a == b) { }           /* ✗ 比较的是两个数组的【地址】，永远不相等 */
if (strcmp(a, b) == 0) { }/* ✓ */
```

**为什么？** 因为 `a` 和 `b` 是两个不同的数组，住在内存的不同位置。`a == b` 比较的是"地址是不是同一个"，答案是不一样。

🔸 **规则：C 里比较字符串必须用 `strcmp`。**

**③ `strcpy` 和 `strcat` 不检查长度**

```c
char d[5];
strcpy(d, "hello world");     /* ✗ 目标只有 5 字节，写越界了 */
```

**这两个函数会一直写下去，不管目标装不装得下。** 目标数组要留够空间：

```c
char d[100];
strcpy(d, "hello world");     /* ✓ */
```

### 不能整体赋值、不能直接用 `=` 拷贝

```c
char a[] = "hello";
char b[10];

b = a;                /* ✗ 编译错误：数组不能整体赋值 */
strcpy(b, a);         /* ✓ 用 strcpy */
```

**这条规则和一维数组一样**（第 10 课），因为数组名是地址，不是变量。

## 4. ⚠️ 字符串指针：`char *` 和 `char []` 的区别

这是本课最容易糊涂的地方。

```c
char a[] = "hello";       /* 字符数组 */
char *p  = "hello";       /* 指向字符串字面量的指针 */
```

**看起来一样，实际上大不相同**：

| | `char a[] = "hello"` | `char *p = "hello"` |
|---|---|---|
| 是什么 | 一个**数组**，内容可以被改 | 一个**指针**，指向只读的字面量 |
| `a[0] = 'H'` | ✓ 可以改 | **✗ 崩溃！**（字面量在只读内存区） |
| `a = 别的` | ✗ 不能 | ✓ 可以（改指向） |
| `sizeof` | 6（数组大小） | 8（指针大小） |

⚠️ **改字符串字面量会导致程序崩溃**：

```c
char *p = "hello";
p[0] = 'H';              /* ✗ Segmentation fault */
```

**好消息**：编译器会警告你：

```
warning: ISO C++ forbids converting a string constant to 'char *'
```

🔸 **实用规则**：

| 你要干什么 | 怎么写 |
|---|---|
| 需要一个能修改的字符串 | `char s[100] = "内容";` 或 `char s[] = "内容";` |
| 只需要读、不修改 | `char *p = "内容";` 或者函数参数 `char *s` |

**函数参数里的 `char *s` 最常用**，因为它能接收上面两种写法传进来的东西：

```c
int my_strlen(char *s)          /* 参数写 char *s 或 char s[] 都行 */
{
    int n = 0;
    while (s[n] != '\0') {      /* 或者写 while (*s++) n++; */
        n++;
    }
    return n;
}
```

**为什么参数能用 `char *s`？** 因为调用时传数组名，传的就是首地址，正好是一个指针。

## 5. 指针的算术运算：字符串遍历的基础

**指针可以加减整数**，含义是"往后移动 n 个元素"：

```c
char s[] = "hello";
char *p = s;            /* p 指向 'h' */

printf("%c\n", *p);     /* h */
p++;                    /* p 往后移一个字符，现在指向 'e' */
printf("%c\n", *p);     /* e */
printf("%s\n", p);      /* ello —— 从 p 开始打印到 \0 */
```

### 🔸 遍历字符串的两种写法

**写法一：用下标**（清楚，推荐新手）

```c
for (int i = 0; s[i] != '\0'; i++) {
    printf("%c", s[i]);
}
```

**写法二：用指针**（老练，上机题常见）

```c
char *p;
for (p = s; *p != '\0'; p++) {
    printf("%c", *p);
}
```

**这两种完全等价。** `s[i]` 和 `*(s + i)` 是同一个东西——**这就是为什么数组和指针在 C 里总是纠缠在一起**：

```c
s[i]  等价于  *(s + i)
```

🔸 **记住这个等式**，它是理解 C 字符串代码的钥匙。看到 `*(s + i)` 就翻译成 `s[i]`，反之亦然。

**简写技巧**（上机题里常见）：

```c
while (*p) {            /* *p 非 0 就是没到 \0，因为 \0 的值就是 0 */
    ...
    p++;
}
```

因为 `\0` 的值是 0，所以 `while (*p)` 和 `while (*p != '\0')` 完全一样。

## 6. 指针数组：`char *words[10]`

**指针数组**就是"一个数组，每个元素都是指针"。处理一堆字符串时非常有用。

```c
char *words[3] = {"apple", "banana", "cherry"};
```

```
   words[0] ──→ "apple"
   words[1] ──→ "banana"
   words[2] ──→ "cherry"
```

**对比二维字符数组**：

```c
char words2[3][20] = {"apple", "banana", "cherry"};
```

```
   words2[0] = "apple\0.............."   每行固定 20 字节
   words2[1] = "banana\0............."
   words2[2] = "cherry\0............."
```

| | `char *w[3]` | `char w[3][20]` |
|---|---|---|
| 内存 | 3 个指针 + 字符串本身 | 3×20 字节（可能浪费） |
| 每个串长度 | 可以不一样 | 都受 20 限制 |
| 能修改内容吗 | 不能（指向字面量） | 能 |
| 排序交换 | **只交换指针（快）** | 要复制整个字符串（慢） |

🔸 **指针数组最大的优势：交换两个字符串只需要交换指针，不用搬字符。**

```c
/* 用指针数组，交换超简单 */
char *t = words[i];
words[i] = words[j];
words[j] = t;
```

**这就是 `int FindNoVowel(char *str[], int num, char res[][20])` 为什么第一个参数用 `char *str[]`** —— 因为要对名字表排序，用指针数组交换起来最方便。

⚠️ **函数的参数 `char *str[]` 和 `char **str` 是等价的**，都表示"指向指针的指针"（也就是指针数组）。

## 7. 本课最少必要记忆

1. **字符串 = 以 `\0` 结尾的字符数组**，长度要留出 `\0` 的位置
2. **`strlen` 不含 `\0`**；**`sizeof` 是数组总字节数**，两者不同
3. **比较字符串必须用 `strcmp`**，不能用 `==`
4. **`s[i]` 等价于 `*(s + i)`**
5. **`char *p = "abc"` 不能改内容**，要改就用 `char s[] = "abc"`

## 8. 新手最常犯的 3 个错

**① 用 `==` 比较字符串**

```c
if (a == b) { }              /* ✗ 比较地址 */
if (strcmp(a, b) == 0) { }   /* ✓ */
```

**② 忘了 `\0` 的位置**

```c
char s[5] = "hello";         /* ✗ 装不下 \0 */
char s[6] = "hello";         /* ✓ */
char s[] = "hello";          /* ✓ 让编译器算 */
```

**③ 用 `scanf("%s")` 读带空格的输入**

```c
char s[100];
scanf("%s", s);              /* ✗ 输入 "hello world" 只能读到 "hello" */
fgets(s, 100, stdin);        /* ✓ */
```
