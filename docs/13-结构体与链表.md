# 13 · 结构体与链表

> **本课内容：结构体 struct / typedef / 单向链表 / 文件初步**
> 这是全课程**概念最多**的一课。分两块：**结构体**（把相关数据打包，很好懂）和**链表**（用指针把一个个结构体串起来，需要一点想象力）。我会从"为什么需要它"讲起。

---

## 1. 为什么需要结构体

先看一个具体问题：**存一个学生的信息**。

```c
/* 用分开的数组 —— 能实现，但很别扭 */
char names[100][20];
int  ids[100];
int  scores[100];
int  n = 0;
```

**问题**：

- **4 个数组要同步维护**。删除一个学生，你得在 4 个数组里各删一次，而且要保证下标对应
- **排序时**要同时交换 4 个数组的元素，容易漏
- **传参时**要传 4 个数组，参数列表长得难看

**根本原因**：`names[5]`、`ids[5]`、`scores[5]` 明明描述同一个学生，却是三个毫不相干的数组。

**结构体的作用：把描述同一个东西的数据打包成一个整体。**

```c
struct Student {
    char name[20];
    int  id;
    int  score;
};

struct Student s;            /* 现在 s 就是一个整体 */
```

```
   s ┌──────────────────────────┐
     │ name:  "张三"            │
     │ id:    2026001           │
     │ score: 95                │
     └──────────────────────────┘
        一个变量，三个字段，打包在一起
```

🔸 **一句话：结构体就是"自定义的数据类型"，把一堆相关的变量捆成一捆。**

有了结构体，你就能把"一个学生的全部信息"当成**一个整体**来传递和使用，而不用开三个互不相干的变量并时刻记着它们仨是一组的。

（如果你熟悉别的语言：结构体有点像"只有字段、没有方法的类"，也有点像字段写死的字典。正因为字段是编译时就定死的，C 的结构体比动态字典快得多，写错字段名编译器也能立刻帮你抓出来。）

## 2. 定义和使用结构体

### 定义

```c
struct Student {            /* struct + 名字 + { 字段列表 } + 分号 */
    char name[20];
    int  id;
    int  score;
};                          /* ⚠️ 末尾必须有分号！这是最常见的错误 */
```

⚠️ **末尾的分号绝对不能漏。** 漏了会报一堆莫名其妙的错（比如把下一个函数的返回值类型搞乱）。

### 声明变量和访问字段

```c
struct Student s;                      /* 声明一个 Student 变量 */

strcpy(s.name, "张三");                /* 用 . 访问字段 */
s.id = 2026001;
s.score = 95;

printf("%s %d %d\n", s.name, s.id, s.score);
```

🔸 **点号 `.` 是"访问字段"的运算符**，读作"s 的 name"。

⚠️ **字符串字段不能用 `=` 赋值**：

```c
s.name = "张三";           /* ✗ 编译错误：数组不能整体赋值 */
strcpy(s.name, "张三");    /* ✓ 用 strcpy */
```

因为 `name` 是 `char[20]`，是个数组（第 12 课讲的规矩）。

### 初始化

```c
struct Student s = {"张三", 2026001, 95};       /* 按字段顺序初始化 */
struct Student t = {.id = 5, .name = "李四"};   /* 指定字段名（C99，可选） */
```

### 整体赋值：这个可以！

```c
struct Student a = {"张三", 1, 95};
struct Student b;

b = a;                     /* ✓ 可以！结构体支持整体赋值 */
```

🔸 **注意对比**：

| 类型 | 能整体赋值吗 |
|---|---|
| 数组 | **✗ 不能**（`int a[5]; b = a;` 是错的） |
| 结构体 | **✓ 能**（`b = a;` 把每个字段都拷贝过去） |

**为什么？** 因为数组名是地址，结构体变量是"真正的变量"。这是 C 的一个设计特点，上机题爱考。

## 3. `typedef`：给类型起个短名字

`struct Student` 每次都要写 `struct`，太啰嗦。`typedef` 可以起别名：

```c
typedef struct Student {
    char name[20];
    int  id;
    int  score;
} Student;                  /* ← 别名 Student */

/* 之后就可以省掉 struct 了 */
Student s1;                 /* 等价于 struct Student s1; */
```

🔸 **`typedef` 的读法**：`typedef 原类型 新名字;`

**⚠️ 别名的位置容易看错**：

```c
typedef struct node {
    int data;
    struct node *next;
} NODE;
/* ↑ 别名 NODE 在最后这个位置，不是 struct 后面 */
```

**⚠️ 结构体内部的自引用必须写 `struct node *next`，不能写 `NODE *next`**：

```c
typedef struct node {
    int data;
    struct node *next;      /* ✓ 必须写完整的 struct node */
    NODE *next;             /* ✗ 别名还没定义完，编译器不认 */
} NODE;
```

**为什么？** 因为在结构体定义体内部，`typedef` 还没执行完，`NODE` 这个名字还不存在。所以自引用要用原名字。

🔸 **这是链表定义的标准写法，背下来**：

```c
typedef struct node {
    /* 数据字段 */
    int data;
    /* 指针字段，指向同类型的下一个节点 */
    struct node *next;
} NODE;
```

## 4. 结构体指针：`->` 运算符

```c
Student s = {"张三", 1, 95};
Student *p = &s;                /* p 指向 s */

/* 两种访问方式，完全等价 */
printf("%s\n", (*p).name);      /* ✗ 能跑，但括号很难看 */
printf("%s\n", p->name);        /* ✓ 标准写法，箭头 */
```

🔸 **`->` 是"通过指针访问字段"的运算符。** 规则：

| 你手上是什么 | 用什么 |
|---|---|
| 结构体变量 | `.` |
| 结构体指针 | `->` |

**`p->name` 就是 `(*p).name` 的简写。** 因为 `*p.name` 会被理解成 `*(p.name)`（点号优先级更高），所以必须加括号，太麻烦，于是发明了 `->`。

⚠️ **最常见的错误：把 `.` 和 `->` 用混**

```c
Student s;
Student *p = &s;

p.name          /* ✗ p 是指针，要用 p->name */
s->name         /* ✗ s 是变量，要用 s.name */
```

好消息：这两种错误都是**编译错误**，不会悄悄出错：

```
error: member reference type 'Student *' is a pointer; did you mean to use '->'?
```

编译器还会提示你用 `->`，很友好。

## 5. 链表：为什么要用它

### 数组的局限

```c
int a[100];         /* 最多 100 个 */
```

**问题**：

1. **容量定死**。要 101 个怎么办？只能重写代码。
2. **插入和删除很贵**。想在第 0 个位置插入一个元素，得把后面所有元素往后挪：

```c
/* 在数组开头插入一个元素 */
for (int i = n; i > 0; i--) {
    a[i] = a[i - 1];        /* 全部后移一位 */
}
a[0] = newValue;
n++;
```

**数组里存了 100 万个元素，这个操作就要搬 100 万次。**

### 链表的思路

**链表**用一组"节点"，每个节点除了数据，还存着**下一个节点的地址**。

```
   head
    ↓
  ┌──────┬──────┐    ┌──────┬──────┐    ┌──────┬──────┐
  │ data │ next │───→│ data │ next │───→│ data │ next │───→ NULL
  └──────┴──────┘    └──────┴──────┘    └──────┴──────┘
   节点1               节点2               节点3          结束标志
```

🔸 **关键点**：

- **节点在内存里可以不连续**（数组必须连续）
- **节点数量可以随时增减**（用 `malloc` 动态申请）
- **插入删除只需要改几个指针**，不用搬数据
- **`NULL` 表示"没有下一个了"**，是链表的结束标志

**对比一下插入操作**：

```
数组：插入到开头 → 所有元素后移        （搬 100 万次）
链表：插入到开头 → 改两个指针          （2 次操作）

   head ──→ 新节点 ──→ 原来的第一个节点
```

⚠️ **链表的代价**：**不能像数组那样用下标直接访问**。要找第 100 个元素，必须从 head 开始一个一个走。这叫"顺序访问"。

| | 数组 | 链表 |
|---|---|---|
| 随机访问第 i 个 | **O(1) 瞬间** | O(n) 要走 i 步 |
| 插入/删除 | O(n) 要搬数据 | **O(1) 改指针** |
| 容量 | 固定 | **随时增减** |
| 内存 | 连续 | 分散 |

🔸 **选择原则**：频繁按下标访问 → 数组；频繁插入删除 → 链表。

## 6. 动态内存：`malloc` 和 `free`

链表节点的数量是运行时才知道的，所以不能用普通数组，要用 `malloc` **动态申请内存**。

```c
#include <stdlib.h>             /* malloc 和 free 在这个头文件里 */

NODE *p = (NODE *)malloc(sizeof(NODE));
```

### 逐个部分拆开

| 部分 | 含义 |
|---|---|
| `malloc(大小)` | 向系统申请"这么多字节"的内存，返回这块内存的首地址 |
| `sizeof(NODE)` | 一个 NODE 结构体占多少字节 |
| `(NODE *)` | 把返回的 `void *` 强制转换成 `NODE *` |
| `p` | 指向新申请的节点 |

🔸 **标准写法背下来：`(类型 *)malloc(sizeof(类型))`。**

### ⚠️ `malloc` 的三个要点

**① 必须检查是否成功**

```c
NODE *p = (NODE *)malloc(sizeof(NODE));
if (p == NULL) {
    /* 内存不够了（申请失败） */
    return NULL;
}
```

内存不足时 `malloc` 返回 `NULL`。**直接使用 `NULL` 指针会崩溃。** 上机题里可以不写这个检查，但工程代码必须写。

**② 新申请的内存是未初始化的**

```c
NODE *p = (NODE *)malloc(sizeof(NODE));
printf("%d\n", p->data);        /* ✗ 垃圾值 */
p->data = 0;                    /* ✓ 自己初始化 */
p->next = NULL;                 /* ✓ 别忘了这个！ */
```

⚠️ **`p->next = NULL;` 特别容易忘。** 忘了的话，这个节点的 next 是垃圾值，后面遍历链表时会走到野指针上，直接崩溃。

**③ 用完了要 `free`**

```c
free(p);                        /* 释放这块内存 */
p = NULL;                       /* 好习惯：置空，防止误用 */
```

**C 没有垃圾回收**。`malloc` 申请的内存，只有你显式 `free` 才会还回去。申请了不释放就是**内存泄漏**。

⚠️ **上机题和练习里通常不要求 free**（程序马上就结束了，操作系统会回收）。但你应该知道这件事。

## 7. 链表的三个基本操作

以这个节点类型为例（本课都按这个来）：

```c
typedef struct node {
    int data;
    struct node *next;
} NODE;
```

### ① 遍历

```c
for (NODE *p = head; p != NULL; p = p->next) {
    printf("%d ", p->data);
}
```

🔸 **这是链表的万能模板，背下来。** 三步：

1. `p = head` 从第一个节点开始
2. `p != NULL` 一直走到最后一个（最后一个节点的 next 是 NULL）
3. `p = p->next` 每次跳到一个节点

**⚠️ 最常见的错误：循环条件写成 `p->next != NULL`**

```c
for (NODE *p = head; p->next != NULL; p = p->next)   /* ✗ 最后一个节点不会被处理 */
```

写 `p->next != NULL` 会**漏掉最后一个节点**。除非你确实想漏掉它（比如删除操作要拿到前驱），否则一律用 `p != NULL`。

### ② 创建（尾插法）

**尾插法**：新节点接到链表末尾，保持插入顺序。

```c
NODE *create(int n)
{
    NODE *head = NULL;
    NODE *tail = NULL;              /* 记住尾巴，避免每次从头找 */

    for (int i = 0; i < n; i++) {
        NODE *p = (NODE *)malloc(sizeof(NODE));

        p->data = i + 1;
        p->next = NULL;             /* ⚠️ 新节点先置空 */

        if (head == NULL) {
            /* 第一个节点：head 和 tail 都指向它 */
            head = p;
            tail = p;
        } else {
            /* 接到尾巴后面，然后尾巴后移 */
            tail->next = p;
            tail = p;
        }
    }

    return head;
}
```

🔸 **两个关键点**：

1. **第一个节点要特殊处理**（head 还是 NULL 的时候）
2. **用一个 `tail` 记住尾巴**，否则每次插入都要从头走到尾，效率是 O(n²)

**头插法**（新节点插到最前面）更简单，但顺序是反的：

```c
NODE *create_reverse(int n)
{
    NODE *head = NULL;

    for (int i = 0; i < n; i++) {
        NODE *p = (NODE *)malloc(sizeof(NODE));
        p->data = i + 1;
        p->next = head;             /* 新节点的 next 指向原来的头 */
        head = p;                   /* head 移到新节点 */
    }

    return head;
}
```

### ③ 删除某个节点

**删除比插入难，需要记住"前驱"**。因为要把前驱的 next 跳过被删节点。

```c
NODE *delete_node(NODE *head, int value)
{
    NODE *cur = head;
    NODE *prev = NULL;

    /* 第一步：找到要删的节点，同时记住它的前驱 */
    while (cur != NULL && cur->data != value) {
        prev = cur;
        cur = cur->next;
    }

    if (cur == NULL) {
        return head;                /* 没找到，原样返回 */
    }

    /* 第二步：摘掉它 */
    if (prev == NULL) {
        /* 要删的是第一个节点（head 本身） */
        head = cur->next;
    } else {
        /* 让前驱跳过当前节点 */
        prev->next = cur->next;
    }

    free(cur);                      /* 释放内存 */
    return head;
}
```

🔸 **两个易错点**：

1. **删第一个节点时要改 head**，所以要判断 `prev == NULL`。**忘了这一步，删头节点会失败。**
2. **`prev->next = cur->next;` 这个顺序不能反**。如果先 `prev->next = cur->next` 再找 cur 就丢了。这里其实没问题，但记住原则：**先接好链，再释放内存**。

**更简单的技巧：用"二级指针"或者"带头节点"的链表**，可以避免"删头节点"的特殊情况。但上机题里一般按上面的写法就行。

### ④ 插入（在指定位置）

```c
/* 在 value 后面插入一个值为 newVal 的节点 */
void insert_after(NODE *head, int value, int newVal)
{
    NODE *p = head;

    while (p != NULL && p->data != value) {
        p = p->next;
    }

    if (p == NULL) {
        return;                     /* 没找到 */
    }

    NODE *q = (NODE *)malloc(sizeof(NODE));
    q->data = newVal;

    q->next = p->next;              /* ⚠️ 顺序不能反！ */
    p->next = q;
}
```

⚠️ **`q->next = p->next;` 必须在 `p->next = q;` 之前。**

```
   正确顺序：
   第1步：q->next = p->next          第2步：p->next = q
   ┌───┐    ┌───┐    ┌───┐          ┌───┐    ┌───┐    ┌───┐
   │ p │───→│ q │───→│ c │          │ p │───→│ q │───→│ c │
   └───┘    └───┘    └───┘          └───┘    └───┘    └───┘
             ↑                                  ↑
        q 先接上 c                          p 再指向 q

   如果反了：
   第1步（错的）：p->next = q         第2步：q->next = p->next
   ┌───┐    ┌───┐                        p->next 现在是 q
   │ p │───→│ q │    c 丢了！          q->next = q  → 自己指向自己！
   └───┘    └───┘                       链表断了，c 找不回来了
```

**这是链表操作最经典的错误**，上机题里"完善程序题"经常考这个顺序。

## 8. 本课最少必要记忆

1. **结构体把相关数据打包**，定义末尾**必须有分号**
2. **访问字段：变量用 `.`，指针用 `->`**
3. **结构体能整体赋值（`b = a`），数组不能**
4. **`typedef` 别名写在最后**；结构体自引用要写 `struct node *next`
5. **链表三件套**：`malloc` 申请、遍历用 `p != NULL`、插入时**先接后断**

## 9. 新手最常犯的 3 个错

**① 结构体定义末尾漏分号**

```c
struct Student {
    char name[20];
}                       /* ✗ 漏了分号 */
struct Student2 { ... };
```

**症状**：报错位置很奇怪，比如"`struct Student2` 前面缺少分号"或者一堆类型错误。**看到莫名其妙的报错，先去检查上一个结构体定义末尾有没有分号。**

**② 忘了给新节点的 next 置 NULL**

```c
NODE *p = (NODE *)malloc(sizeof(NODE));
p->data = 5;
/* ✗ 忘了 p->next = NULL; */
```

**症状**：遍历链表时程序崩溃（`Segmentation fault`），或者打印出乱七八糟的内容。因为最后一个节点的 next 是垃圾值，遍历时走到了不属于程序的内存。

**③ 插入时顺序反了**

```c
p->next = q;                /* ✗ 先断链，后面的节点丢了 */
q->next = p->next;
```

**症状**：插入之后链表"少了一截"，或者死循环（`q->next` 指向自己）。
