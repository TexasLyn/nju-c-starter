# 02 · 变量、类型和 sizeof

> **本课内容：数据类型、sizeof、运算符、scanf、顺序结构**
> 这一课讲清楚 C 里最基本、也最反直觉的一件事：**为什么每个变量都要先说明它装什么**。理解了这件事，后面所有的"莫名其妙"都有解释。

---

## 1. 为什么 C 一定要写类型

有些语言里，变量像一个**万能标签**：

```
x = 5
x = "你好"      # 完全没问题，x 换成字符串了
x = [1, 2, 3]   # 也没问题，x 换成列表了
```

你可以随时把标签贴到任何东西上，语言自己会在运行的时候看这是什么东西。

C 不是。C 里变量是一个**贴着尺寸标签的盒子**：

```c
int x = 5;      // 开一个装整数的盒子
x = "你好";      // ✗ 编译错误！盒子里装不下字符串
```

**为什么要这么麻烦？** 因为 C 想让程序跑得尽量快。编译的时候，如果编译器已经知道每个盒子有多大、装什么，它就能提前把内存安排好、把运算指令选好。代价就是你要多打字。

🔸 **记住这个类比**：C 的变量是"定尺寸的盒子"，类型就是尺寸标签。这一课后面所有的坑，都来自"盒子大小"这件事。

**一句话总结**：C 要求你在写代码的时候就把"这块内存装什么"讲清楚，而不是等到程序跑起来才决定。

---

## 2. 五种基本类型

C 的类型很多，但你现在只需要记这五个：

| 类型 | 装什么 | 占几个字节 | 怎么打印 | 例子 |
|---|---|---|---|---|
| `int` | 整数 | 4 | `%d` | `int n = 100;` |
| `long` | 更大的整数 | 8 | `%ld` | `long big = 1000000;` |
| `float` | 小数（精度低） | 4 | `%f` | `float f = 3.14f;` |
| `double` | 小数（精度高，**默认用它**） | 8 | `%lf` | `double pi = 3.14159;` |
| `char` | 单个字符 | 1 | `%c` | `char c = 'A';` |

**关于 `float` 和 `double`**：都表示小数，`double` 精度更高。**一律用 `double`**，因为 `float` 精度不够，算几轮之后误差就出来了（第 3 课会专门讲浮点误差）。注意 `float` 的字面量要加后缀 `f`，不写会被当成 `double`。

**关于 `char`**：用**单引号**，只能装一个字符。`'A'` 是 char，`"A"` 是字符串——**这是两样完全不同的东西**，后面第 12 课讲字符串时会重点说。现在只要记住：**单引号是字符，双引号是字符串**。

### 各类型的范围（了解即可）

| 类型 | 范围 |
|---|---|
| `int` | 约 −21 亿 ～ 21 亿（−2³¹ ～ 2³¹−1） |
| `long` | 约 ±9.2×10¹⁸ |
| `double` | 约 ±1.7×10³⁰⁸，有效数字约 15～17 位 |

`int` 装不下超过 21 亿的数。装不下会怎样？**不会报错**，它会悄悄绕回到负数——这叫**溢出**。这是后面「新手最常犯的错」里的一条。

## 3. sizeof：量一量盒子多大

有个运算符叫 `sizeof`，专门用来量一个类型或变量占几个字节：

```c
#include <stdio.h>

int main(void)
{
    printf("int 占 %zu 个字节\n", sizeof(int));
    printf("double 占 %zu 个字节\n", sizeof(double));

    int x = 10;
    printf("变量 x 占 %zu 个字节\n", sizeof(x));   // 和 sizeof(int) 一样
    return 0;
}
```

⚠️ `sizeof` **后面要加括号**，看起来像函数但它其实是运算符。另外打印 `sizeof` 的结果要用 `%zu`（这是 `unsigned long` 的一种写法，现在照抄就行）。

**为什么这个运算符值得单独学？** 因为在 C 里，"一个东西占多大"是你必须操心的事——数组有多长、字符串有多长、`malloc` 要申请多少内存，全都围绕字节数转。

## 4. 运算符

| 运算符 | 含义 | 例子 | 结果 |
|---|---|---|---|
| `+ - *` | 加减乘 | `3 * 4` | `12` |
| `/` | 除 | `7 / 2` | ⚠️ **`3`**，不是 3.5 |
| `%` | 取余数 | `7 % 2` | `1` |
| `++` | 加 1 | `i++` | `i` 变成 `i+1` |
| `--` | 减 1 | `i--` | `i` 变成 `i-1` |

### ⚠️ 本课最大的坑：整数除法

```c
7 / 2       // 3     ← 两个整数相除，结果自动砍掉小数部分！
7 / 2.0     // 3.5   ← 有小数参与，才是真正的除法
```

**规则**：`/` 两边**都是整数**时，C 做的是**整除**，结果的小数部分**直接扔掉**（不是四舍五入！）。

```c
5 / 2       // 2   （0.5 被扔掉）
-5 / 2      // -2  （朝零方向砍）
1 / 3       // 0   （不是 0.333，是 0）
```

想要小数结果，**至少让一边是小数**：

```c
double r = 7 / 2.0;      // 3.5   ✓
double r2 = (double)7 / 2;  // 3.5  ✓  (double) 是强制转换
double r3 = 7 / 2;       // 3.0   ✗ 先整除得 3，再存进 double 变 3.0
```

最后一行特别迷惑：`r3` 的类型是 `double`，但值还是 `3.0`。**类型是 `double` 不代表运算过程中会变成小数**，运算在赋值之前就完成了。

### `%` 取余：很有用的工具

```c
7 % 2      // 1
100 % 10   // 0
123 % 10   // 3    ← 取一个数的个位
123 / 10   // 12   ← 砍掉个位
```

**最后两行是万能公式**，拆数字全靠它：

| 想要 | 写法 |
|---|---|
| 取最低位（个位） | `n % 10` |
| 去掉最低位 | `n / 10` |
| 取最低两位 | `n % 100` |
| 取最高位（4 位数） | `n / 1000` |

本课的练习几乎全靠这两招。

⚠️ `%` 只能用于整数。写 `7.5 % 2` 会编译报错。

## 5. 自增自减

```c
int i = 5;
i++;        // i 变成 6，等价于 i = i + 1
i--;        // i 变成 5，等价于 i = i - 1
i += 3;     // i 变成 8，等价于 i = i + 3
i -= 2;     // i 变成 6
i *= 2;     // i 变成 12
```

🔸 **先记住这几种写法**，用得很多。`i++` 和 `++i` 的区别（一个先取值再加，一个先加再取值）第 5 课讲循环时再说，现在不用管。

## 6. printf 和 scanf 的格式符

这是一张**必须记牢**的表，写错格式符不会报错，只会输出垃圾：

| 类型 | printf（输出） | scanf（输入） |
|---|---|---|
| `int` | `%d` | `%d` |
| `long` | `%ld` | `%ld` |
| `float` | `%f` | `%f` |
| `double` | `%f` | **`%lf`** |
| `char` | `%c` | `%c` |
| 字符串 | `%s` | `%s` |
| `sizeof` 结果 | `%zu` | — |

**注意 `double` 那一行**：打印用 `%f`，但读入必须用 `%lf`（多一个 `l`）。这是唯一一处 printf 和 scanf 不一样的地方，也是上机题爱考的点。

### 关于 `&` 这个符号

```c
int x;
scanf("%d", &x);   // 注意这个 &
```

**为什么 scanf 要多写一个 `&`，而 printf 不用？**

🔸 **现在先记住"scanf 的变量前面要加 `&`"就行**，第 8 课讲指针时会回来解释：`&` 的意思是"这个变量在内存里的地址"。scanf 要把数据送到那个地址去，所以得告诉它地址在哪。

现在只要记住一条铁律：**`scanf` 里除了数组和字符串（第 10、12 课会遇到），其他变量前面都要加 `&`。漏了 `&` 程序往往不报错但结果全错**，非常难查。

### 关于 `gets()`（如果你用的是教材）

不少教材和参考代码里用 `gets()` 读一行字符串。**`gets` 已经从 C 语言标准里删掉了**，现代编译器会直接报错或者给一个刺眼的警告。替代方案：

```c
// 教材写法（Turbo C / VS2010 时代的机器上可能还能用，现代环境用不了）
char str[100];
gets(str);

// 现代写法（用这个）
char str[100];
fgets(str, 100, stdin);           // 读一行，会在末尾保留换行符
str[strcspn(str, "\n")] = '\0';   // 手动去掉那个换行符（第 12 课讲原理）
```

现在只需要知道有这么回事，第 12 课讲字符串时会展开。

## 7. 本课最少必要记忆

1. **声明要写类型**：`int x = 5;`、`double y = 3.5;`
2. **`/` 两边都是整数时是整除**，`7/2` 得 `3`。想要小数就写 `7/2.0`
3. **`%` 取余数**：`n % 10` 得个位，`n / 10` 去掉个位
4. **格式符**：`int` 用 `%d`，`double` 打印 `%f` 读入 `%lf`，`char` 用 `%c`
5. **`scanf` 的变量前面要有 `&`**

## 8. 新手最常犯的 3 个错

**① 整数除法，小数被悄悄扔掉**

```c
int a = 7, b = 2;
double r = a / b;              // r 是 3.0，不是 3.5！

double r = (double)a / b;      // ✓ 3.5
double r = a / 2.0;            // ✓ 3.5
```

**这个错误不会报错，程序照跑，只是答案是错的。** 写除法时养成习惯：先在心里问一句"这两个数是什么类型"。

**② 忘了 `&`**

```c
int x;
scanf("%d", x);      // ✗ 漏了 &
scanf("%d", &x);     // ✓
```

漏了 `&` 的后果：程序可能直接崩溃（`Segmentation fault`），也可能不崩但读到乱七八糟的值。**看到"段错误"或者"读进来的数完全不对"，先检查 `&`。**

**③ 格式符和类型对不上**

```c
double d = 3.5;
printf("%d\n", d);       // ✗ 用 %d 打印 double，输出一个莫名其妙的整数
printf("%f\n", d);       // ✓

int n = 10;
printf("%f\n", n);       // ✗ 同理，输出垃圾
printf("%d\n", n);       // ✓
```

`printf` 不会检查你的格式符对不对（它没法检查，参数是运行时才传的）。**格式符写错不会报错，只会打印垃圾值**，这是 C 里最难查的一类问题。
