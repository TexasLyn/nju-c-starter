# 07 · 函数与递归

> **本课内容：函数、返回值、递归**
> 函数是 C 程序的基本组织单位——**写 C 就是写一堆函数然后拼起来**。这一课要把这个能力补上。如果你在别的语言里写过函数，这课主要是把"多写的那些类型"搞清楚。

---

## 1. 从一个加法函数开始

```c
int add(int a, int b)      /* ← 返回值类型 函数名(参数类型 参数名) */
{
    return a + b;
}
```

就这一个函数，包含了函数的**四要素**：函数名（`add`）、参数（`a`、`b`）、返回值（`int`，即返回一个整数）、函数体（花括号里的内容）。

调用它：

```c
int result = add(3, 5);    /* result 是 8 */
```

### 逐块拆解

| 部分 | 怎么写 | 注意 |
|---|---|---|
| 返回值类型 | 写在最前面，**必须有** | 没返回值写 `void` |
| 参数类型 | **每个参数都要单独写类型** | `int a, int b`，不能写 `int a, b` |
| 函数体范围 | 靠花括号 `{}` | 缩进只是给人看的 |
| 返回 | `return a + b;` | **有分号** |
| 调用 | `add(3, 5)` | 和数学函数的写法一样 |

⚠️ **参数类型必须一个一个写**：

```c
int add(int a, int b)      /* ✓ 每个参数都带类型 */
int add(int a, b)          /* ✗ 编译错误：b 没有类型 */
```

这是新手很容易漏的地方——因为直觉上"都是 int 嘛，写一遍就行了"，但 C 不这么认为。

## 2. 函数必须写在 `main` 之前（或者先声明）

这是 C 的一个**结构性**要求，别的语言里常常没这条规矩。

C 是**从上往下编译**的。编译器读到 `add(3, 5)` 的时候，必须已经知道 `add` 是什么样子（几个参数、什么类型、返回什么），否则不知道该怎么生成代码。

```c
/* ✗ 这样写会报错 */
#include <stdio.h>

int main(void)
{
    printf("%d\n", add(3, 5));    /* 编译器：add 是谁？没见过 */
    return 0;
}

int add(int a, int b)             /* 定义在下面，太晚了 */
{
    return a + b;
}
```

报错信息类似：

```
error: call to undeclared function 'add'
```

**两种解决办法**：

**方法一：把函数定义写在 `main` 前面**（简单，适合小程序）

```c
int add(int a, int b)
{
    return a + b;
}

int main(void)
{
    printf("%d\n", add(3, 5));    /* ✓ 已经见过 add 了 */
    return 0;
}
```

**方法二：函数声明（原型）**——先告诉编译器"有这么个函数"，定义放后面（正规做法）

```c
#include <stdio.h>

int add(int a, int b);            /* ← 函数声明：末尾有分号，没有函数体 */

int main(void)
{
    printf("%d\n", add(3, 5));    /* ✓ 编译器已经知道 add 的样子了 */
    return 0;
}

int add(int a, int b)             /* ← 函数定义：有函数体 */
{
    return a + b;
}
```

**声明的样子和定义的第一行一模一样，只是末尾加分号。**

🔸 **习惯**：`#include` 之后集中写所有函数声明，`main` 放中间或最后，函数定义放最后。这是正规 C 代码的组织方式，也是多文件编程的基础。

⚠️ **`#include <stdio.h>` 里其实就是一堆函数声明。** 它告诉编译器 `printf` 长什么样（返回 `int`，第一个参数是字符串）。这就是为什么漏了 `#include <stdio.h>` 就报 `call to undeclared function 'printf'`。

## 3. void：没有返回值

```c
void print_line(void)          /* 没有返回值，也不接受参数 */
{
    printf("----------\n");
}

int main(void)
{
    print_line();               /* 调用时不要用 printf 接收结果 */
    return 0;
}
```

- **`void` 作为返回值类型**：这个函数不返回东西，不需要 `return`（或者写 `return;` 也行）
- **`(void)` 作为参数列表**：不接受任何参数

⚠️ **`(void)` 不是"参数是 void 类型"，而是"没有参数"的意思。**

### 什么时候用 void，什么时候返回值

| 情况 | 怎么写 |
|---|---|
| 算一个值给调用者用 | 有返回值，如 `int add(...)` |
| 只打印/只修改传入的东西 | `void` |
| 计算并打印，但调用者不需要结果 | 可以 `void`，也可以返回值但调用时不接 |

🔸 **练习里的约定**：题目说"写一个函数求 xx"，就**要有返回值**；题目说"写一个函数输出 xx"，就是 `void`。

## 4. ⚠️ 参数是"值传递"：函数里改不了外面

这是 C 函数最重要的一个性质，也是新手最容易踩的坑。

```c
void try_change(int x)
{
    x = 999;              /* 修改的是副本 */
}

int main(void)
{
    int a = 5;
    try_change(a);
    printf("%d\n", a);    /* 输出 5，不是 999！ */
    return 0;
}
```

**为什么？** 因为 C 调用函数时，是把 `a` 的**值拷贝一份**传进去。函数里操作的是那个副本，改副本不影响原件。

```
    main 里的 a          try_change 里的 x
    ┌──────┐             ┌──────┐
    │  5   │  ──拷贝──→  │  5   │  → 改成 999
    └──────┘             └──────┘
     还是 5               （函数结束后就没了）
```

**这里要特别提醒**：有些语言里，把一个大对象（比如数组、列表）传进函数，函数里改了外面也会变。**C 不是这样，C 里所有参数都是拷贝**，包括数组（数组的情况稍微特殊，第 10 课专门讲）。

### 那怎么让函数修改外面的变量？

**用指针。** 这是第 8、9 课的主题。现在你先记住这个现象，第 9 课会讲怎么绕过它。

🔸 **现在只需要记住一条**：C 的函数里改不了外面的变量（除非用指针）。所以函数主要通过**返回值**来传递结果。

## 5. return 的用法

```c
int max_of(int a, int b)
{
    if (a > b) {
        return a;         /* 提前返回 */
    }
    return b;
}
```

**两条规则**：

1. **执行到 `return`，函数立刻结束**，后面的代码不执行
2. **有返回值的函数，所有路径都必须有 `return`**

```c
/* ⚠️ 有隐患的写法 */
int check(int n)
{
    if (n > 0) {
        return 1;
    }
    /* n <= 0 的时候没写 return！ */
}
```

这个函数在 `n <= 0` 时会返回**垃圾值**（内存里恰好残留的数据）。编译器会警告：

```
warning: non-void function does not return a value in all control paths
```

**看到这个警告一定要改**，它不是可有可无的提示，是真 bug。

## 6. 递归：函数自己调用自己

**递归**就是函数内部再调用自己。写法上是"把大问题拆成同类型的小问题"。

### 例：阶乘

`n! = n × (n-1) × (n-2) × ... × 1`。这个定义本身就是递归的：**`n!` 等于 `n` 乘以 `(n-1)!`**。

```c
int fact(int n)
{
    if (n <= 1) {
        return 1;              /* 出口：不能再拆了 */
    }
    return n * fact(n - 1);    /* 拆小一点，再问自己 */
}
```

对着 `fact(4)` 走一遍，你就明白递归在干什么了：

```
fact(4) = 4 * fact(3)
              fact(3) = 3 * fact(2)
                            fact(2) = 2 * fact(1)
                                          fact(1) = 1   ← 到这里出口，开始往回算
                            fact(2) = 2 * 1 = 2
              fact(3) = 3 * 2 = 6
fact(4) = 4 * 6 = 24
```

**一层一层往下拆，拆到不能再拆（出口），再一层一层把结果带回来。**

### 递归必须有"出口"

**出口**（也叫基准情况）是递归终止的条件。没有出口就是无限递归，程序会崩溃：

```
Segmentation fault: 11        ← 栈溢出，递归太深把内存用完了
```

```c
/* ✗ 没有出口 */
int bad(int n)
{
    return n * bad(n - 1);      /* 永远递归下去 → 崩溃 */
}
```

🔸 **写递归的固定套路**：

```
1. 先写出口：什么情况下直接返回，不再递归？
2. 再写递归：把问题变小一点，用自己解决
```

**永远先写出口。** 先写出口，就不会忘。

### 递归的执行过程（一定要理解）

以 `fact(4)` 为例：

```
fact(4)
  → 需要 4 * fact(3)
      → 需要 3 * fact(2)
          → 需要 2 * fact(1)
              → 出口！返回 1
          ← 返回 2 * 1 = 2
      ← 返回 3 * 2 = 6
  ← 返回 4 * 6 = 24
```

**注意两个阶段**：

1. **往下的阶段**：一层层调用，每次参数变小，直到碰到出口。这时还没算出任何结果。
2. **往上的阶段**：从出口开始，一层层把结果乘回去。

🔸 **理解这一点，才能看懂递归题。** 上机题里的"阅读程序题"经常给你一段递归代码，问输出是什么——你要在脑子里模拟这两阶段。

## 7. 递归 vs 循环：该用哪个

**任何递归都能改写成循环**，反过来也一样。那什么时候用递归？

| 用递归 | 用循环 |
|---|---|
| 问题天然是"分层的"（树、目录、汉诺塔） | 简单的重复计数 |
| 代码短且清楚（阶乘、斐波那契、进制转换） | 递归很深会栈溢出 |
| 深度不大（几十层以内） | 深度上千层 |

**⚠️ 递归的代价**：每次调用都要占用内存（叫栈空间），深度太大会崩溃。算 `fact(100000)` 会崩，用循环就没事。

**练习里**：题目要求"用递归实现"就必须用递归；没要求的话，简单问题用循环更保险。

## 8. 递归实用例子：进制转换

**"十进制转任意 n 进制"** 是必须用递归的经典题，因为**输出顺序是反的**：

```c
void convert(int n, int base)
{
    if (n >= base) {
        convert(n / base, base);    /* 先递归处理高位 */
    }

    int d = n % base;               /* 再输出本位 */
    if (d < 10) {
        printf("%d", d);
    } else {
        printf("%c", 'A' + d - 10);  /* 10 以上用字母 */
    }
}
```

**为什么必须递归？** 因为取余数是从低位开始的（`n % base` 先得到最低位），但输出要从高位开始。**递归天然实现了"倒序输出"**：

```
convert(13, 2)
  → 13 >= 2，先递归 convert(6, 2)
      → 6 >= 2，先递归 convert(3, 2)
          → 3 >= 2，先递归 convert(1, 2)
              → 1 < 2，不递归了，输出 1        ← 最高位先输出！
          ← 输出 3 % 2 = 1
      ← 输出 6 % 2 = 0
  ← 输出 13 % 2 = 1
结果：1101   ✓ （13 的二进制）
```

**关键点**：`printf` 写在递归调用**后面**，所以它在"往上的阶段"才执行，输出顺序自然就反过来了。

🔸 **这个技巧叫"利用递归栈实现倒序"**，练习和上机题里很常见。

## 9. 本课最少必要记忆

1. **函数定义**：`返回类型 函数名(参数类型 参数名, ...) { ... }`
2. **函数要先声明或先定义**，`main` 里才能调用
3. **参数是值传递**，函数里改不了外面的变量（要用指针，第 9 课）
4. **递归必须有出口**，否则栈溢出崩溃
5. **递归两阶段**：一层层往下调用，碰到出口后一层层往上传结果

## 10. 新手最常犯的 3 个错

**① 函数写在 main 后面，没声明**

```c
int main(void) { add(1, 2); }     /* ✗ call to undeclared function 'add' */
int add(int a, int b) { return a + b; }
```

**② 有返回值的函数，某条路径忘了 return**

```c
int sign(int x) {
    if (x > 0) return 1;
    if (x < 0) return -1;
    /* ✗ x == 0 的时候返回垃圾值 */
}
```

编译器会警告 `non-void function does not return a value in all control paths`。**看到就改。**

**③ 递归忘了出口**

```c
int fact(int n) {
    return n * fact(n - 1);      /* ✗ 没有出口，直接崩 */
}
```

**症状**：程序运行后立刻 `Segmentation fault: 11`（或者 `zsh: segmentation fault`）。**看到这个崩溃又有递归，先检查出口。**
