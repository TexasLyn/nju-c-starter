# 06 · 迭代法：让计算机"逼近"答案

> **本课内容：循环 + 迭代法 / 数值方法**
> 前面几课的循环都是"数数"（从 1 数到 100）。这一课要学一种新用法：**用循环一步步逼近答案**。这类题在练习里占的分量不小，而且有固定的套路。

---

## 1. 什么是迭代法

有些方程**没法用公式解出精确答案**，比如 `cos(x) = x`。你没法像解一元二次方程那样套公式。

那就换个思路：**先随便猜一个值，然后按某个规则不断改进这个猜测，改进到足够精确为止。**

```
猜一个值  →  用规则算出更好的值  →  再算更好的  →  ...  →  足够精确了，停
              ↑                                              ↓
              └────────── 循环重复 ──────────────────────────┘
```

这就是**迭代法**。它不需要你会解方程，只需要你能写出一条"让答案变好一点"的规则。

**为什么这题要用循环？** 因为你不知道要迭代多少次。可能 4 次就收敛，也可能 20 次。所以循环条件是"**精度够不够**"，而不是"循环了多少次"。

---

## 2. 迭代法的标准骨架

所有迭代题都是这个形状：

```c
double x = 初始猜测;                    /* ① 猜一个起点 */

while (/* 还没达到精度要求 */) {          /* ② 循环直到够精确 */
    double new_x = /* 用规则算出下一个值 */;  /* ③ 迭代规则 */
    /* 判断是否收敛 */
    x = new_x;                          /* ④ 更新 */
}
```

🔸 **记住这四个要素：初值、停止条件、迭代规则、更新。** 缺一个就会出问题：

| 缺什么 | 后果 |
|---|---|
| 初值 | 编译错误，或者从垃圾值开始 |
| 停止条件 | 死循环 |
| 迭代规则 | 死循环（值不变） |
| 更新（`x = new_x`） | 死循环（`x` 不变） |

**"死循环"是迭代题最常见的故障。** 排查方法：把每次迭代的 `x` 打印出来，看它是不是在变、是不是在往答案靠。

---

## 3. 用哪个条件判断"够精确了"

有两种写法，效果一样：

**写法一：看前后两次的差**

```c
double x = 1.0;
double new_x;
int iter = 0;

do {
    new_x = /* 规则 */;
    iter++;
} while (fabs(new_x - x) >= 1e-6 && iter < 100);
```

意思：**新值和旧值已经几乎一样了，就说明收敛了，可以停。**

⚠️ 这里必须用 `fabs`（浮点绝对值），因为差值可能是负的。`fabs(a) < 1e-6` 的意思是"a 和 0 的差距小于百万分之一"。

**写法二：看函数值够不够接近 0**

```c
while (fabs(f(x)) >= 1e-6) { ... }
```

意思：**把 x 代进方程，如果结果已经很接近 0，说明 x 就是答案。**

两种都对。看题目怎么要求。

### 🔸 必须加一个"次数上限"

```c
while (fabs(new_x - x) >= 1e-6) { ... }        /* ⚠️ 有风险 */
while (fabs(new_x - x) >= 1e-6 && iter < 100) { ... }   /* ✓ 安全 */
```

**为什么？** 如果迭代规则写错了，或者遇到不收敛的情况，程序会永远转下去。加个次数上限，最多转 100 次就退出，你能看到问题出在哪，而不是程序卡死。

**这是工程习惯，也是上机题保险。** 迭代题请一律加上 `&& iter < 100` 之类。

## 4. 幂级数展开：用迭代累加求和

**幂级数**（比如泰勒级数）就是把一个函数写成无穷多项相加。计算机算 `sin(x)` 用的就是这个方法。

以 sin 为例：

```
sin(x) = x - x³/3! + x⁵/5! - x⁷/7! + ...
```

直接算每一项都要重新算阶乘，很浪费。**技巧是：后一项可以由前一项乘一个简单的因子得到。**

```
第 k 项  T_k = (-1)^k · x^(2k+1) / (2k+1)!

观察相邻两项的关系：
    T_{k+1} / T_k = -x² / [(2k+2)(2k+3)]
```

所以：

```c
double term = x;        /* 第一项就是 x */
double sum = x;

int k = 1;
while (fabs(term) >= 1e-8) {
    term = -term * x * x / ((2 * k) * (2 * k + 1));   /* 递推得到下一项 */
    sum = sum + term;
    k++;
}
```

🔸 **这个"用前一项推后一项"的写法叫递推**，是幂级数题的标准解法。**不要一项一项从零算阶乘**（容易溢出，而且慢）。

**为什么用 `k` 而不是直接用阶乘？** 因为 `(2k)(2k+1)` 是和前一项的**比值**，不需要知道阶乘本身多大。sin(1) 的级数其实要算到第 20 项左右才够精确，20! 是个天文数字，直接算会溢出。用递推就完全避开了这个问题。

## 5. 牛顿迭代法

这是求方程根最常用的方法，也是**收敛最快**的（每轮有效数字翻倍）。

**几何意义**：在当前的猜测点画一条切线，切线与 x 轴的交点就是下一个猜测。

**公式**：

```
x_{n+1} = x_n − f(x_n) / f'(x_n)
```

其中 `f(x) = 0` 是你要解的方程，`f'(x)` 是它的导数。

### 例：解 cos(x) − x = 0

```
f(x)  = cos(x) − x
f'(x) = −sin(x) − 1          ← 对 f 求导
```

```c
double x = 1.0;              /* 初值随便猜一个 */
int iter = 0;

while (1) {
    double f  = cos(x) - x;      /* 函数值 */
    double df = -sin(x) - 1;     /* 导数值 */
    double new_x = x - f / df;   /* 牛顿公式 */

    iter++;
    if (fabs(new_x - x) < 1e-6 || iter > 100) {
        x = new_x;
        break;
    }
    x = new_x;
}
```

**结果**：x ≈ 0.739085（这个数叫 Dottie 数，是 cos(x)=x 的唯一解）。

**初值怎么选？** 一般题目会给（"初值取 1.0"）。如果没给，就猜一个和答案差不多大的数。**初值选得离答案太远，牛顿法可能不收敛**，这是它唯一的缺点。

## 6. 二分法

**思路最简单**：如果一个函数在 `[lo, hi]` 两端一正一负，那中间一定有个零点（因为函数图像是连续的，要穿过 0）。

于是：

1. 取中点 `mid = (lo + hi) / 2`
2. 看 `f(mid)` 和 `f(lo)` 是不是同号
   - 同号 → 零点在 `[mid, hi]`，把 `lo` 换成 `mid`
   - 异号 → 零点在 `[lo, mid]`，把 `hi` 换成 `mid`
3. 每轮区间缩小一半，缩小到足够小就停

```c
double lo = -1.0, hi = 1.0;        /* 题目给的区间 */
int iter = 0;

while (hi - lo > 1e-6 && iter < 200) {
    double mid = (lo + hi) / 2;

    if (exp(mid) + mid > 0) {      /* f(mid) 是正的 */
        hi = mid;                  /* 零点在左半边 */
    } else {
        lo = mid;                  /* 零点在右半边 */
    }
    iter++;
}

double root = (lo + hi) / 2;
```

**结果**：x ≈ −0.567143（这是 e^x + x = 0 的解）。

### ⚠️ 二分法的两个要点

**① 初值必须一正一负（异号）**

这是二分法的前提。如果 `f(lo)` 和 `f(hi)` 同号，说明区间里可能没有零点（或者有偶数个），二分法就失效了。**做题前先检查一下题目给的区间是不是真的异号。**

**② 精度和区间长度的关系**

停止条件是 `hi - lo > 1e-6`，意思是"区间宽度还大于百万分之一就继续"。等区间小到 10⁻⁶ 时，区间里任何一个数都可以认为是答案（因为误差已经在要求之内了）。

**二分法比牛顿法慢**（这题用了 21 次，牛顿法只要 4 次），但它**一定收敛**（只要能保证异号），不会像牛顿法那样发散。**稳但有代价。**

## 7. 三种方法的对比（上机题选择题爱考）

| 方法 | 需要什么 | 收敛速度 | 可靠性 |
|---|---|---|---|
| 幂级数递推 | 会写递推公式 | 看级数 | 高 |
| 牛顿迭代 | 会求导数 | **最快**（4 次） | 初值不好会失败 |
| 二分法 | 只要区间异号 | 慢（约 20 次） | **一定成功** |

## 8. 本课最少必要记忆

1. **迭代法四要素**：初值、停止条件、迭代规则、更新
2. **停止条件用 `fabs(差值) < 1e-6`**，并且**一定加次数上限**
3. **幂级数用递推**：后一项 = 前一项 × 因子，不要从头算阶乘
4. **牛顿公式**：`x = x - f(x)/f'(x)`，需要导数
5. **二分法**靠区间异号，每轮砍一半，稳定但慢

## 9. 新手最常犯的 3 个错

**① 忘了更新 x，死循环**

```c
while (fabs(new_x - x) >= 1e-6) {
    new_x = x - f / df;
    /* ✗ 忘了 x = new_x; → x 永远不变 → 死循环 */
}
```

**② 用 `abs` 而不是 `fabs` 判断精度**

```c
while (abs(new_x - x) >= 1e-6)    // ✗ abs 是给整数用的！
```

`abs` 接受整数参数，传个 `double` 进去会被**截断成整数**。比如 `abs(0.0000001)` 得到 `0`，于是判断立刻失败（认为已经收敛），循环一次就退出，答案是错的。

**看到结果明显不对但程序不报错，检查这里。** 记住：**带 f 的 `fabs` 才是浮点数的绝对值**（f = float）。

**③ 幂级数从头算阶乘导致溢出**

```c
/* ✗ 每一项重新算阶乘 */
for (int k = 0; k < 20; k++) {
    sum += pow(-1, k) * pow(x, 2*k+1) / factorial(2*k+1);
    /* 20! ≈ 2.4×10^18，int 早就溢出了，long 也快撑不住 */
}

/* ✓ 用递推 */
term = x;
while (fabs(term) >= 1e-8) {
    term = -term * x * x / ((2*k) * (2*k+1));
    sum += term;
    k++;
}
```
