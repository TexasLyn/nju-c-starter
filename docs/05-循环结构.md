# 05 · 循环结构：for、while 和穷举法

> **本课内容：循环结构、穷举、素数、分解质因数**
> C 有三种循环：`for`、`while`、`do-while`。前两个你大概见过，第三个是 C 里挺特别的一个。这一课把三种都讲清楚。

---

## 1. 三种循环，对照看

同一个任务——打印 0 到 4——三种写法：

```c
/* ① for —— 最常用，循环次数已知时用它 */
for (int i = 0; i < 5; i++) {
    printf("%d\n", i);
}
```

```c
/* ② while —— 条件满足就一直转，循环次数不确定时用它 */
int i = 0;
while (i < 5) {
    printf("%d\n", i);
    i++;
}
```

```c
/* ③ do-while —— 先做一次，再判断要不要继续 */
int i = 0;
do {
    printf("%d\n", i);
    i++;
} while (i < 5);
```

三者的区别，一句话：

| 循环 | 什么时候用 | 特点 |
|---|---|---|
| `for` | **次数已知**（"跑 5 次"、"遍历数组"） | 初始化、条件、步进写在一行里，最不容易漏 |
| `while` | **次数未知**（"一直读到文件结束"、"直到精度够高"） | 条件写在开头，可能一次都不执行 |
| `do-while` | **至少要执行一次**（"先输入，再问要不要继续"） | 条件写在**末尾**，后面**必须有分号** |

⚠️ `do-while` 末尾那个分号 `} while (i < 5);` 千万别漏，漏了会报一堆莫名其妙的错。

后面几课你会看到：`for` 用来遍历，`while` 用来迭代（第 6 课专门讲），`do-while` 用来写菜单。

### 重点看 `for`：括号里用两个分号隔成三块

其他语言里可能是 `for i in range(5)` 这种写法——C 的 `for` 长得不一样，但干的是同一件事：**从 0 开始、小于 5、每次加 1**。

```c
for ( 初始化 ; 继续条件 ; 每轮结束后的动作 )
      ↑          ↑              ↑
   只执行一次   每轮开头检查    每轮末尾执行
```

**完整的执行顺序**（这个必须搞清楚，上机题常考）：

```
1. 初始化      i = 0
2. 判断条件    i < 5 ?  → 真，进入循环体
3. 循环体      printf
4. 步进        i++
5. 回到第 2 步
```

⚠️ **注意：第 4 步"步进"发生在循环体之后、下次判断之前。** 所以是「先执行体，再加 1」，不是「先加 1，再执行体」。这个顺序搞错了，边界值就会差 1。

```c
/* 从 1 打印到 5：注意条件用的是 <= */
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);       // 1 2 3 4 5
}

/* 也是 5 次，但用的是 < */
for (int i = 0; i < 5; i++) {
    printf("%d ", i);       // 0 1 2 3 4
}
```

🔸 **`<` 还是 `<=` 是循环里最需要小心的地方。** 记法：**从 0 开始数 n 个用 `< n`，从 1 开始数到 n 用 `<= n`。**

## 2. `int i` 写在 for 里面还是外面

```c
/* 写法 A：在 for 里声明（C99 之后支持，也是现代推荐写法） */
for (int i = 0; i < 5; i++) {
    printf("%d\n", i);
}

/* 写法 B：在外面声明（教材常用，兼容老编译器） */
int i;
for (i = 0; i < 5; i++) {
    printf("%d\n", i);
}
```

**两种都对。** 你的教材用的是写法 B（因为教材面向 VS2010 / Turbo C，那些老环境不支持写法 A）。

需要注意的区别：**写法 A 的 `i` 出了循环就没了**，写法 B 的 `i` 循环结束后还存在，值等于让它退出的那个数：

```c
int i;
for (i = 0; i < 5; i++) { }
printf("%d\n", i);     // 输出 5 ← 循环结束时 i 恰好是 5

for (int j = 0; j < 5; j++) { }
printf("%d\n", j);     // ✗ 编译错误：j 已经不存在了
```

🔸 **本套材料里一律用写法 A**（在 for 里声明），更清楚。但你看教材答案时见到写法 B 不要觉得奇怪。

## 3. while 和 do-while

```c
/* while：先判断，再执行。可能一次都不执行 */
int i = 0;
while (i < 5) {
    printf("%d\n", i);
    i++;                    // ⚠️ 别忘了这句，否则死循环
}
```

```c
/* do-while：先执行一次，再判断。至少执行一次 */
int i = 0;
do {
    printf("%d\n", i);
    i++;
} while (i < 5);            // ⚠️ 末尾有分号！
```

⚠️ **`do-while` 的 `while(...)` 末尾必须有分号。** 这是唯一一个末尾带分号的循环结构，很多人会漏。漏了会报很奇怪的错（编译器以为下一行是 while 的一部分）。

### 什么时候用哪个

| 场景 | 用 |
|---|---|
| 次数明确（循环 n 次、遍历数组） | `for` |
| 次数不明确，靠条件退出（读到 -1 停止） | `while` |
| 无论如何至少要执行一次（先做再验证） | `do-while` |

### `while` 和 `for` 可以互相改写

```c
/* 这两种完全等价 */
for (int i = 0; i < 5; i++) { ... }

int i = 0;
while (i < 5) { ...; i++; }
```

**`for` 更适合"次数明确"，`while` 更适合"条件驱动"。** 选哪个看哪种读起来更自然。

## 4. ⚠️ 死循环：最需要警惕的坑

循环条件如果永远为真，程序就卡死不退出了。你会看到程序一直转，什么也不输出，得手动停掉。

```c
/* ✗ 忘了 i++，i 永远是 0，条件永远成立 */
int i = 0;
while (i < 5) {
    printf("%d\n", i);
}

/* ✗ 条件写反了 */
for (int i = 0; i > 5; i++) { ... }    // 0 > 5 是假，一次都不执行（不是死循环，是空转）

/* ✗ 步进方向反了 */
for (int i = 0; i < 5; i--) { ... }    // i 越来越小，永远到不了 5 → 死循环
```

**排查方法**：在循环里插一句 `printf("i=%d\n", i);`，跑一下看看 `i` 是怎么变的。如果 `i` 不变，就是忘了步进。

**故意写死循环**也是有用的：

```c
while (1) {          // 1 永远是真，所以永远循环
    /* 靠 break 跳出 */
}
```

🔸 **`while (1)` 是"死循环"的标准写法**，很多菜单程序都用它。靠 `break` 退出。判别真假用的是第 4 课学的「0 是假，非 0 是真」。

## 5. break 和 continue

| 关键字 | 作用 |
|---|---|
| `break` | **立刻跳出整个循环**，不再循环 |
| `continue` | **跳过本轮剩下的部分**，直接进入下一轮 |

```c
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;              // i 到 5 就直接结束循环
    }
    printf("%d ", i);       // 输出 1 2 3 4
}
```

```c
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue;           // 偶数跳过，不打印
    }
    printf("%d ", i);       // 输出 1 3 5 7 9
}
```

**区别一句话**：`break` 是**不干了**，`continue` 是**这一个不干，下一个继续**。

### 关于 break 的常见误解

`break` 只能跳出**它所在的那一层**循环。嵌套循环里，`break` 跳不出外层：

```c
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) break;      // 只跳出内层，外层还继续
    }
    printf("i=%d\n", i);        // 这行会执行 3 次
}
```

要跳出两层，得用一个标志变量或者 `goto`（教材里可能会提 `goto`，但**练习里别用**，可读性差）。

## 6. 穷举法：循环最典型的用法

**穷举**（也叫枚举）就是"把所有可能的情况都试一遍"。这是计算机最擅长的事，也是练习和上机题里最常见的题型。

**套路固定**：

```
1. 想清楚有哪些"变量"（要尝试的东西）
2. 给每个变量定好范围
3. 一层循环一个变量，逐个试
4. 在循环里判断当前组合是否符合条件
5. 符合就计数 / 输出 / 保存
```

### 例：求 x1 + x2 + x3 + x4 = 30 有多少组正整数解

```c
int count = 0;

for (int x1 = 1; x1 <= 27; x1++) {
    for (int x2 = 1; x2 <= 27; x2++) {
        for (int x3 = 1; x3 <= 27; x3++) {
            for (int x4 = 1; x4 <= 27; x4++) {
                if (x1 + x2 + x3 + x4 == 30) {
                    count++;
                }
            }
        }
    }
}
printf("count=%d\n", count);
```

**为什么范围写 27？** 因为四个数都是正整数，最小是 1，所以任何一个最大只能是 30−1−1−1 = 27。范围写小了会漏解，写大了只是多算几次（结果一样）。

🔸 **穷举法的范围宁可写大一点，只是慢一点；写小了就会漏答案。** 新手最常犯的错就是把范围写得太紧。

### 例：判断素数

```c
int n = 97;
int isPrime = 1;                  /* 先假设它是素数 */

if (n < 2) {
    isPrime = 0;                  /* 0 和 1 不是素数 */
} else {
    for (int i = 2; i < n; i++) {
        if (n % i == 0) {         /* 找到了能整除它的数 */
            isPrime = 0;
            break;                /* 已经确定不是素数了，不用再找 */
        }
    }
}

printf("%d\n", isPrime ? 1 : 0);
```

🔸 **这个"先假设成立，发现问题就推翻"的模式非常重要**，后面判断回文数、判断完数全靠它。记住这个套路：

```c
int flag = 1;                 // 先假设"是"
for (...) {
    if (某个反例) {
        flag = 0;             // 推翻
        break;                // 早退，省时间
    }
}
if (flag) { /* 确实是 */ }
```

## 7. 本课最少必要记忆

1. **`for (初始化; 条件; 步进)`**，三段用分号隔开
2. **`while` 先判断后执行，`do-while` 先执行后判断**（末尾有分号！）
3. **循环里一定要有让条件最终变假的东西**，否则死循环
4. **`break` 跳出整个循环，`continue` 跳过本轮**
5. **穷举法套路**：定范围 → 套循环 → 判断条件 → 计数

## 8. 新手最常犯的 3 个错

**① 忘了步进，死循环**

```c
int i = 0;
while (i < 5) {
    printf("%d\n", i);       // ✗ 忘了 i++，程序卡死
}
```

**② 边界差 1（off-by-one）**

```c
/* 想输出 1 到 5 */
for (int i = 1; i < 5; i++) { }     // ✗ 只到 4
for (int i = 1; i <= 5; i++) { }    // ✓

/* 想遍历数组 a[0..n-1] */
for (int i = 0; i <= n; i++) { }    // ✗ 越界！访问了不存在的 a[n]
for (int i = 0; i < n; i++) { }     // ✓
```

**数组越界是 C 里最危险的错误**：它不会报错，可能读到垃圾值、也可能让程序崩溃，甚至看起来"正常工作了"然后在上机题时出错。第 10 课会详说。

**③ do-while 末尾漏分号**

```c
do {
    ...
} while (i < 5)         // ✗ 漏了分号
```
