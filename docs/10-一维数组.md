# 10 · 一维数组

> **本课内容：一维数组**
> 数组是"一排同样类型的数据"。别的语言里的 list 是它的近亲，但 C 的数组**规矩多得多**：长度固定、不记得自己多长、越界不报错。这一课把这些规矩讲清楚。

---

## 1. 先说数组是什么

数组就是**一排连续的、同类型的盒子**：

```
int a[5];      →   ┌────┬────┬────┬────┬────┐
                   │ a[0]│ a[1]│ a[2]│ a[3]│ a[4]│
                   └────┴────┴────┴────┴────┘
                     连续排在一起，每个装一个 int
```

三个关键点，先记住：

1. **下标从 0 开始**，所以 5 个元素的合法下标是 `0 ~ 4`，**没有 `a[5]`**
2. **长度在声明时定死**，`int a[5]` 就永远是 5 个，不能变多
3. **数组自己不记得有多长**，你得另外用变量记着

最后一条听起来很怪，但它是 C 数组一切麻烦的根源——因为数组名在 C 里其实只是"第一个元素的位置"，本身不包含长度信息。

### 和其他语言的 list 比一比

| | 别的语言的 list | C 数组 |
|---|---|---|
| 长度 | 可变，随便加 | **声明时定死，不能改** |
| 知道自己多长吗 | 知道，`len(a)` | **不知道**，你得自己记住 |
| 索引范围 | 越界报错 | **越界不报错，直接读写别的内存** |
| 负数索引 | `a[-1]` 是最后一个 | **不是**，`a[-1]` 是数组前面那块内存 |
| 整体赋值 | `b = a` 复制一份 | `b = a` **编译错误** |
| 传进函数 | 传引用，函数能改 | 传地址，函数也能改 |

🔸 **最重要的一条**：**C 数组不检查越界。** 这是 C 里最危险的坑，第 3 节专门讲。

## 2. 声明和初始化

```c
int a[5];                         /* 5 个 int，值全是垃圾 */
int b[5] = {1, 2, 3, 4, 5};       /* 全部初始化 */
int c[5] = {1, 2, 3};             /* ⚠️ 后面两个自动补 0：1 2 3 0 0 */
int d[] = {1, 2, 3, 4};           /* 长度自动推出是 4 */
int e[5] = {0};                   /* 全部是 0 —— 这是清零的标准写法 */
double f[3] = {1.5, 2.5, 3.5};
char g[10] = "hello";             /* 字符串，第 12 课细讲 */
```

⚠️ **四个必须记住的点**：

**① 长度必须是常量，不能是变量**

```c
int n = 5;
int a[n];                  /* ✗ 标准 C 不允许（C99 的变长数组是扩展） */
int a[5];                  /* ✓ 写字面量 */
#define N 100
int b[N];                  /* ✓ 用宏定义 */
```

**遇到"输入 n 然后处理 n 个数"，就用一个足够大的固定长度**：

```c
#define MAXN 1000
int a[MAXN];
int n;
scanf("%d", &n);
/* 只用 a[0] 到 a[n-1]，剩下的空间浪费掉，但没问题 */
```

**② 部分初始化，剩下的自动补 0**

```c
int c[5] = {1, 2, 3};      /* 实际是 1 2 3 0 0 */
```

**③ 不初始化就是垃圾值**

```c
int a[5];                  /* 里面的值是内存里的残留数据，完全不可预测 */
int a[5] = {0};            /* ✓ 想清零就这么写 */
```

注意 `= {0}` 是**清零的惯用写法**，不能写成 `= {0, 0, 0, 0, 0}`（虽然也对，但没必要）。

**④ 数组不能整体赋值、不能整体比较**

```c
int a[3] = {1, 2, 3};
int b[3];

b = a;                     /* ✗ 编译错误！数组名不是变量 */
if (a == b) { }            /* ✗ 比较的是地址，永远不相等 */

/* ✓ 要复制就逐个元素复制 */
for (int i = 0; i < 3; i++) {
    b[i] = a[i];
}
```

🔸 **为什么 `b = a` 不行？** 因为**数组名在 C 里不是一个"变量"，而是一个"地址"**（数组第一个元素的地址）。地址是常量，不能被赋值。所以复制数组只能用循环逐个元素搬。

## 3. ⚠️ 越界：C 里最危险的错误

```c
int a[5] = {1, 2, 3, 4, 5};

a[5] = 100;        /* ⚠️ 下标最大只能到 4！a[5] 已经越界了 */
a[10] = 200;       /* ⚠️ 越得更远 */
a[-1] = 300;       /* ⚠️ 负数也越界 */
```

**这三个都不会报错。** 编译能过，运行也不崩（通常）。

**为什么？** 因为 C 把数组当成"一块内存的起始地址"。`a[i]` 的含义是"从起始地址往后数 i 个元素的位置"。编译器**不检查** i 是不是在合法范围内——它只按这个公式去算地址。

```
   int a[5] 在内存里：
   下标:    0     1     2     3     4   |  5     6   ...
         ┌─────┬─────┬─────┬─────┬─────┬─────┬─────┐
         │  1  │  2  │  3  │  4  │  5  │ ??? │ ??? │
         └─────┴─────┴─────┴─────┴─────┴─────┴─────┘
                                          ↑
                              a[5] 读到这里，这块内存可能属于别的变量
```

**后果分三种**：

| 情况 | 后果 |
|---|---|
| 读到越界位置 | 得到一个垃圾值，程序看起来"正常"但答案错 |
| 写到越界位置 | **悄悄改坏了别的变量的值** |
| 越界太远 | 访问到不属于程序的内存 → `Segmentation fault` 崩溃 |

**第一种和第二种最可怕**，因为没有报错信号。你可能会花几小时找"为什么这个变量的值会自己变"，原因是别的循环越界写到了它。

### 🔸 防越界的习惯

```c
/* 遍历数组的标准写法 */
int a[5];
for (int i = 0; i < 5; i++) {      /* ✓ 用 < 不是 <= */
    a[i] = i;
}

/* 如果长度是变量 n */
for (int i = 0; i < n; i++) {      /* ✓ */
    ...
}
for (int i = 0; i <= n; i++) {     /* ✗ 最后一次 i == n 就越界了 */
    ...
}
```

**口诀：`i < n` 是对的，`i <= n` 是错的**（这里的 n 是元素个数）。

⚠️ 例外：如果你想遍历到"第 n 个元素"（下标 n-1），那 `i <= n-1` 也对，但写成 `i < n` 更不容易错。

## 4. 数组有多长？自己记

C 数组不记得自己多长。你有三种办法知道长度：

**① 用 `sizeof`（只在"数组"这个身份还在的时候有效）**

```c
int a[5];
int len = sizeof(a) / sizeof(a[0]);      /* 5 */

printf("%zu\n", sizeof(a));              /* 20（5 个 int，每个 4 字节） */
printf("%zu\n", sizeof(a[0]));           /* 4 */
```

`sizeof(a) / sizeof(a[0])` 是标准写法：**总字节数 ÷ 单个元素字节数 = 元素个数**。

⚠️ **这个方法在函数里失效！** 原因下面马上讲。

**② 用一个单独的变量记住**

```c
int a[100];
int n;
scanf("%d", &n);         /* n 是实际用了几个 */
for (int i = 0; i < n; i++) { ... }
```

**这是实际写代码时最常用的方式**，这类题目里也总是给你 n 或者让你自己数。

**③ 用宏定义长度**

```c
#define N 10
int a[N];
for (int i = 0; i < N; i++) { ... }
```

## 5. ⚠️ 数组传给函数：这个和前面讲的"值传递"不一样

第 7 课说"C 的参数是值传递，函数里改不了外面的变量"。**数组是例外。**

看这个例子：

```c
void modify(int a[], int n)         /* 参数写成 int a[] */
{
    a[0] = 999;                     /* 直接改 */
}

int main(void)
{
    int arr[3] = {1, 2, 3};

    modify(arr, 3);
    printf("%d\n", arr[0]);         /* 输出 999 —— 真的被改了！ */
    return 0;
}
```

**为什么这次能改？** 因为**传数组名时，传的是数组第一个元素的地址**，不是整个数组的拷贝。函数收到地址后，就能顺着地址去改原来的数组。

🔸 **两个后果**：

**后果一：函数里用 `sizeof` 拿不到正确的长度**

```c
void f(int a[])
{
    printf("%zu\n", sizeof(a));     /* 输出 8，不是数组的总字节数！ */
}
```

**因为参数 `int a[]` 实际上被编译器当成 `int *a`（指针）。** `sizeof(指针)` 得到的是指针自己占的字节数（8 字节），不是数组的。

**所以：数组传给函数时，必须额外传一个长度参数。**

```c
void f(int a[], int n)              /* ✓ 标准做法 */
{
    for (int i = 0; i < n; i++) { ... }
}
```

**后果二：函数里的修改会影响调用者**（这就是它能"原地排序"、"原地删除"的原因）

**参数写法有几种，意思完全一样**：

```c
void f(int a[], int n)      /* 最清楚，推荐 */
void f(int a[5], int n)     /* 5 会被忽略，别被骗 */
void f(int *a, int n)       /* 等价的本质写法 */
```

🔸 **推荐用 `int a[]`**，因为它一眼就能看出"这里要传数组"。

## 6. 数组的典型操作

### 遍历

```c
int a[5] = {3, 1, 4, 1, 5};
int sum = 0;

for (int i = 0; i < 5; i++) {
    sum = sum + a[i];
}
```

### 找最大值

```c
int max = a[0];                    /* ⚠️ 从 a[0] 开始，不要从 0 开始 */
for (int i = 1; i < n; i++) {      /* 从下标 1 开始比 */
    if (a[i] > max) {
        max = a[i];
    }
}
```

🔸 **为什么 `max` 初值取 `a[0]` 而不是 `0`？** 因为如果数组全是负数，`max` 从 0 开始就会得到错误的 0。**从第一个元素开始是最稳的。**

### 统计"有多少个不同的数"

这是第 10 课的经典题，思路是"对每个元素，看它前面有没有出现过"：

```c
int count = 0;

for (int i = 0; i < n; i++) {
    int seen = 0;
    for (int j = 0; j < i; j++) {      /* 只看 i 前面的 */
        if (a[j] == a[i]) {
            seen = 1;
            break;
        }
    }
    if (!seen) {
        count++;                       /* 前面没出现过，是新数据 */
    }
}
```

🔸 **"看它前面有没有出现过"这个思路非常常用**，删除重复、统计频次全靠它。

### 原地删除重复（不借助其他数组）

核心技巧是**用两个下标**：一个负责"扫描"，一个负责"存留下的数据"。

```c
int k = 0;                             /* k 是"存"的位置 */

for (int i = 0; i < n; i++) {
    int seen = 0;
    for (int j = 0; j < k; j++) {      /* 只看已经留下的 */
        if (a[j] == a[i]) {
            seen = 1;
            break;
        }
    }
    if (!seen) {
        a[k] = a[i];                   /* 把新数据存到 k 位置 */
        k++;                           /* k 前进一格 */
    }
}
/* 结束后 k 就是不重复数据的个数，a[0]..a[k-1] 是结果 */
```

**画图理解**（原数组 1 4 2 3 4 1 2 5 5 9）：

```
i=0: a[0]=1，k=0（前面没数据），存 → a[0]=1, k=1
i=1: a[1]=4，看 a[0..0] 有没有 4？没有，存 → a[1]=4, k=2
i=2: a[2]=2，看 a[0..1] 有没有 2？没有，存 → a[2]=2, k=3
i=3: a[3]=3，看 a[0..2] 有没有 3？没有，存 → a[3]=3, k=4
i=4: a[4]=4，看 a[0..3] 有没有 4？有（a[1]），跳过
i=5: a[5]=1，看 a[0..3] 有没有 1？有（a[0]），跳过
i=6: a[6]=2，看 a[0..3] 有没有 2？有（a[2]），跳过
i=7: a[7]=5，看 a[0..3] 有没有 5？没有，存 → a[4]=5, k=5
i=8: a[8]=5，看 a[0..4] 有没有 5？有（a[4]），跳过
i=9: a[9]=9，看 a[0..4] 有没有 9？没有，存 → a[5]=9, k=6
结果：a[0..5] = 1 4 2 3 5 9，k=6
```

🔸 **"双下标"技巧是数组题的核心套路**（一个读一个写），排序、筛选、删除都靠它。

⚠️ **注意 `a[k] = a[i]` 写在判断里面，`k++` 紧跟着。** 别写成先 `k++` 再赋值，那样会跳过一个位置。

### 元素交换

```c
int t = a[i];
a[i] = a[j];
a[j] = t;
```

这就是第 4 课学过的三句交换，只是把变量名换成了数组元素。

## 7. 本课最少必要记忆

1. **长度在声明时定死**，用宏或足够大的固定值
2. **`int a[5] = {0};` 是清零的标准写法**
3. **下标从 0 到 n-1**，`i < n` 是对的，`i <= n` 会越界
4. **越界不报错**，会悄悄读/写别的内存
5. **数组传给函数时，函数能改原数组**，但必须**额外传长度**

## 8. 新手最常犯的 3 个错

**① 越界（最常见的 bug）**

```c
for (int i = 0; i <= n; i++)      /* ✗ 最后一次越界 */
    a[i] = 0;

for (int i = 0; i < n; i++)       /* ✓ */
    a[i] = 0;
```

**② 在函数里用 `sizeof` 求数组长度**

```c
void f(int a[])
{
    int n = sizeof(a) / sizeof(a[0]);    /* ✗ 得到 2（或 8/4），不是真实长度 */
}
```

**必须把长度当参数传进来。**

**③ 以为 `b = a` 能复制数组**

```c
int a[3] = {1,2,3};
int b[3];
b = a;                    /* ✗ 编译错误：array type 'int[3]' is not assignable */

for (int i = 0; i < 3; i++)   /* ✓ 逐个复制 */
    b[i] = a[i];
```

**报错信息里出现 `array type ... is not assignable`，就是这个原因。**
