# 04 · 选择结构：if 和 switch

> **本课内容：选择结构 if / switch**
> `if` 本身不难，这课的重点是 C 特有的两个东西：**`switch`** 和 **花括号的必要性**——后者是新手栽跟头最多的地方。

---

## 1. if 的基本形状

判断分数等级，用 C 写出来是这样：

```c
if (score >= 90) {
    printf("优秀\n");
} else if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}
```

注意三个形状上的细节：

| 细节 | 写错会怎样 |
|---|---|
| 条件外面有**圆括号** | `if score >= 90` ← 少了括号，报 `expected expression` |
| 代码块用**花括号 `{}`** 圈起来 | 见下一节，不写不会报错但逻辑会错 |
| 多分支用 **`else if`**（两个词，中间有空格） | 没这个词，写 `elif` 直接报错 |

⚠️ **`elif` 是某些语言里的写法，C 里没有这个词。** 写 `elif` 会报 `expected expression` 之类的错。C 只有 `else if`。

---

## 2. ⚠️ 花括号不是可选的

这是本课最容易栽的地方。看这段：

```c
if (x > 0)
    printf("正数\n");
    printf("这句话总是会执行！\n");    // ⚠️ 不在 if 里面！
```

因为没有花括号，`if` **只管到它后面的第一条语句**。缩进是骗人的——**C 编译器完全不在乎你的缩进**。上面这段代码的实际含义是：

```c
if (x > 0) {
    printf("正数\n");
}
printf("这句话总是会执行！\n");    // 无条件执行
```

**这就是「缩进骗人」的经典错误。** 而且上机题里特别爱考这个——给你一段缩进很整齐但没有花括号的代码，问你输出是什么。

**对策：养成习惯，`if` 后面永远写花括号，哪怕只有一句话。**

```c
if (x > 0) {
    printf("正数\n");
}
```

看起来啰嗦，但省下的调试时间远超打两个字符的成本。

---

## 3. 条件表达式：几个必须记牢的符号

| 含义 | C 的写法 | ⚠️ |
|---|---|---|
| 相等 | `==` | 见下面第 4 节 |
| 不等 | `!=` | |
| 大于等于 | `>=` | |
| 与（并且） | `&&` | **不能写 `and`** |
| 或（或者） | `\|\|` | **不能写 `or`** |
| 非（取反） | `!` | **不能写 `not`** |

```c
if (a >= 60 && b >= 60) { ... }   /* a 和 b 都及格 */
if (x == 0 || y == 0) { ... }     /* x 或 y 至少一个是 0 */
if (!flag) { ... }                /* flag 是假 */
```

**把 `&&`/`||`/`!` 写成英文单词是新手第 3 大坑**（前两个是漏分号和中文标点）。C 的编译器不认识 `and`，会把它当成一个变量名，然后抱怨"这个变量没定义"。

### 🔸 连续比较要拆成两半

数学课上你可以写 `0 < x < 100`。**C 里不能这么写！** C 会先算 `0 < x`，得到 `1` 或 `0`，再用这个结果去和 `100` 比：

```c
if (0 < x < 100) { }          // ✗ 逻辑完全错了，但能编译通过！
if (0 < x && x < 100) { }     // ✓ 正确写法
```

这个错误很危险：**能编译、能运行、不报错，但判断结果几乎总是错的。** 因为 `0 < x` 的结果是 0 或 1，**永远小于 100**，所以这个条件永远成立。

## 4. ⚠️ `=` 和 `==`：最经典的错误

| 写法 | 含义 |
|---|---|
| `x = 5` | **赋值**：把 5 放进 x |
| `x == 5` | **比较**：x 等于 5 吗？结果是真或假 |

```c
if (x = 5) { }      // ✗ 这是赋值！结果是 5，非 0 就是"真"，所以条件永远成立
if (x == 5) { }     // ✓ 这才是比较
```

好消息：**现代编译器（包括你用的 clang）会对这种写法发警告**：

```
warning: using the result of an assignment as a condition without parentheses
```

看到这个警告，就去检查是不是把 `==` 写成了 `=`。

坏消息：它只是**警告不是错误**，程序还能编译。所以一定要留意警告信息，别只看有没有 error。

**助记技巧**：想写比较的时候，把常量写在左边：

```c
if (5 == x) { }     // 如果不小心写成 if (5 = x)，编译器会直接报错
                    // 因为 5 不是一个能赋值的变量
```

## 5. 真和假：C 里没有 True/False

别的语言里常有 `True` 和 `False` 两个关键字。C 里**没有**（C99 之后可以用 `stdbool.h` 里的 `true`/`false`，但教材基本不用）。

C 的规则很朴素：

| 值 | 当成 |
|---|---|
| **0** | 假 |
| **任何非 0 的数** | 真 |

```c
if (1) { }        // 真，执行
if (-5) { }       // 真！负数也是非 0
if (0) { }        // 假，不执行
if (0.0001) { }   // 真
```

比较表达式的结果也是数字：**真得到 `1`，假得到 `0`**。

```c
int a = (3 > 2);      // a 是 1
int b = (3 < 2);      // b 是 0
printf("%d\n", 5 > 3);   // 输出 1
```

🔸 **这个特性很有用**，后面写"计数"的代码时会用到：

```c
count = count + (x > 0);    // x 是正数就 +1，否则 +0
```

## 6. `&&` 和 `||` 的短路特性

这是上机题爱考、实际也很有用的一个性质。

**`&&`（与）**：左边为假时，**右边根本不会被计算**，因为结果已经确定了（假）。

```c
if (i < n && a[i] > 0) { }     // i >= n 时，a[i] 不会被访问 → 安全
```

**`||`（或）**：左边为真时，**右边根本不会被计算**。

```c
if (n == 0 || 100 / n > 5) { }   // n 是 0 时，除法不会执行 → 避免除零崩溃
```

**这两个例子展示了短路的实际价值**：把"安全检查"写在前面，把"危险操作"写在后面，短路机制自动保护你。

⚠️ 但这也是个坑：**如果右边的表达式有副作用（比如 `i++`），它可能不执行。**

```c
int i = 0;
if (0 && i++) { }        // i++ 不会执行，i 还是 0
printf("%d\n", i);       // 输出 0

int j = 0;
if (1 || j++) { }        // j++ 不会执行，j 还是 0
printf("%d\n", j);       // 输出 0
```

**上机题常见题型**：给你一段带 `i++` 的短路代码，问你最后输出什么。记住规则就行：**`&&` 遇假就停，`||` 遇真就停。**

## 7. switch：多分支的另一条路

当你要根据一个整数值做很多种选择时，`switch` 比一长串 `if-else if` 更清晰：

```c
switch (n) {
    case 1:
        printf("一\n");
        break;
    case 2:
        printf("二\n");
        break;
    case 3:
        printf("三\n");
        break;
    default:
        printf("其他\n");
        break;
}
```

### 规则

1. `switch (表达式)` 里的表达式必须是**整数类型**（`int`、`char`、`long`）。**不能是 `double` 或字符串。**
2. `case` 后面必须是**常量**，比如 `case 1:`、`case 'A':`。**不能写变量**，比如 `case n:` 是错的。
3. **每个 `case` 末尾要写 `break;`**，否则会"掉下去"（下面解释）。
4. `default` 处理所有其他情况，位置随意（一般都放最后）。

### ⚠️ 忘写 break 会"穿透"

这是 `switch` 最大的坑，也是上机题最爱考的：

```c
int n = 2;
switch (n) {
    case 1:
        printf("一\n");
    case 2:
        printf("二\n");     // 没有 break
    case 3:
        printf("三\n");     // 没有 break
    default:
        printf("其他\n");
}
```

输出是：

```
二
三
其他
```

**原因**：`switch` 找到匹配的那个 `case` 之后，就**一直往下执行**，不再判断后面的 `case`，直到遇到 `break` 或者 switch 结束。

### 🔸 这个特性有时是故意的

利用穿透可以写"多个值共用一段代码"：

```c
switch (grade) {
    case 'A':
    case 'a':                    // A 和 a 都走这里
        printf("优秀\n");
        break;
    case 'B':
    case 'b':
        printf("良好\n");
        break;
    default:
        printf("其他\n");
        break;
}
```

这里 `case 'A':` 后面**故意不写代码也不写 break**，让 `'A'` 掉到 `'a'` 那里去。这是标准写法，不是错误。

### switch 能做什么、不能做什么

| 可以 | 不可以 |
|---|---|
| `case 1:` | `case 1.5:` ← 浮点数不行 |
| `case 'A':` | `case "A":` ← 字符串不行 |
| `case 1 + 2:` ← 常量表达式可以 | `case n:` ← 变量不行 |
| `case 0: case 1: ...` 多个 case 共用 | 范围判断 `case 60..100:` |

**如果条件是"大于 60"、"在某个范围"这种，只能用 `if`，不能用 `switch`。**

## 8. 三元运算符（附带一提）

C 有个 `if-else` 的简写形式：

```c
max = (a > b) ? a : b;
```

意思是：**`a > b` 成立就取 `a`，否则取 `b`。** 格式是 `条件 ? 成立时的值 : 不成立时的值`。

C 的写法很紧凑，但**别嵌套用**（`a ? b : c ? d : e` 这种可读性极差）。

## 9. 本课最少必要记忆

1. **`&&` `||` `!`**，不能写 `and` `or` `not`
2. **`==` 是比较，`=` 是赋值**，别搞混
3. **花括号必须写**，缩进不能替代它
4. **0 是假，非 0 是真**，比较的结果是 `1` 或 `0`
5. `switch` 每个 `case` 末尾要 `break`，忘了会穿透

---

## 10. 新手最常犯的 3 个错

**① 把 `and`/`or`/`not` 写成英文单词**

```c
if (a >= 60 and b >= 60) { }     // ✗ 编译错误：use of undeclared identifier 'and'
if (a >= 60 && b >= 60) { }      // ✓
```

**② `=` 和 `==` 混用**

```c
if (x = 0) { }      // ✗ 把 0 赋给 x，然后判断 0（假），条件永远不成立
if (x == 0) { }     // ✓
```

这个错误的可怕之处在于：**它可能恰好"看起来正常工作"**，直到某天 x 恰好变成别的值。留意编译器警告。

**③ 忘写 break，switch 穿透**

```c
switch (n) {
    case 1: printf("一\n");      // ✗ 没有 break
    case 2: printf("二\n"); break;
}
```

输入 1 时会输出"一"和"二"两行。
