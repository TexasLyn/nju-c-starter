## 一句话对照表（贴墙上看）

这张表是「同样的意思，C 怎么写」。**前半段和别的语言几乎一样，后半段是 C 独有的。**

### 一样的部分（扫一眼跳过就行）

| 要干的事 | 常见写法 | C 的写法 |
|---|---|---|
| 赋值 | `x = 5` | `int x = 5;` ← 多一个类型 |
| 分支 | `if x > 0:` | `if (x > 0) { }` ← 多圆括号、多花括号 |
| 多分支 | `elif` | `else if` |
| 循环 n 次 | `for i in range(n):` | `for (int i = 0; i < n; i++) { }` |
| 循环（条件） | `while cond:` | `while (cond) { }` |
| 函数 | `def f(a, b):` | `int f(int a, int b) { }` |
| 返回 | `return a + b` | `return a + b;` ← 多分号 |
| 取数组元素 | `a[i]` | `a[i]` ← 一样 |
| 逻辑与或非 | `and` `or` `not` | `&&` `\|\|` `!` |
| 注释 | `# xxx` | `// xxx` 或 `/* xxx */` |
| 打印 | `print(x)` | `printf("%d\n", x);` ← 要写格式符和 `\n` |
| 输入 | `input()` | `scanf("%d", &x);` ← 要写格式符和 `&` |

**这张表里真正会绊倒你的只有三行**：打印、输入、逻辑运算符。其余都是换个语法外壳。

### 不一样的部分（这几处必须认真读）

| 概念 | 别的语言里 | C 里 | 在哪一课 |
|---|---|---|---|
| **类型** | 变量随便装什么 | **声明时定死，不能改** | [02](02-变量类型和sizeof.md) |
| **整数除法** | `7 / 2` 得 3.5 | **得 3**（小数被扔掉） | [02](02-变量类型和sizeof.md) 第 4 节 |
| **编译** | 没有这回事，直接运行 | **必须先编译，报错分两种** | [01](01-第一个C程序.md) |
| **字符串** | 一个对象，`len()` 拿长度 | **一个字符数组，末尾有 `\0`，长度要自己数** | [12](12-字符串与指针.md) |
| **数组长度** | 数组自己知道 | **数组不知道，得你自己记着** | [10](10-一维数组.md) |
| **越界** | 报错 | **不报错，直接改坏别的内存** | [10](10-一维数组.md) 第 3 节 |
| **传参** | 大对象传引用，函数能改 | **全是值拷贝；要改外面得传指针** | [07](07-函数与递归.md) 第 4 节 |
| **指针** | 被语言藏起来了 | **裸的地址，要自己管** | [08](08-作用域与指针形参.md) |
| **内存** | 自动回收 | **`malloc` 要配对 `free`** | [13](13-结构体与链表.md) |
| **字符串比较** | `s1 == s2` | **`strcmp(s1, s2) == 0`** | [12](12-字符串与指针.md) |

## 三个最常见的「以为一样」的坑

从有基础的人踩坑统计里挑出来的，按踩坑频率排序：

### ① `7 / 2` 不等于 3.5

```c
double r = 7 / 2;         /* r 是 3.0！不是 3.5 */
double r = 7 / 2.0;       /* ✓ 3.5，让一边变成小数 */
double r = (double)7 / 2; /* ✓ 3.5，强制转换 */
```

这个坑的特点是**不报错、程序照跑、答案是错的**。写除法前先问自己：两边是什么类型？

### ② 字符串不能用 `==` 比较

```c
char a[] = "abc", b[] = "abc";
if (a == b) { }               /* ✗ 比的不是内容，是地址，永远不成立 */
if (strcmp(a, b) == 0) { }    /* ✓ */
```

C 的字符串是字符数组，**数组名在表达式里等于第一个字符的地址**，所以 `a == b` 比较的是"两个数组在哪"，不是"两个数组装了什么"。

### ③ 函数里改不了外面的变量

```c
void add_one(int x) { x = x + 1; }   /* 改的是副本 */

int main(void) {
    int a = 5;
    add_one(a);
    printf("%d\n", a);   /* 输出 5，不是 6 */
}
```

**C 的所有参数都是值拷贝。** 想让函数修改调用者的变量，必须传地址（指针）——这就是 [08 课](08-作用域与指针形参.md) 存在的理由，也是 C 里 `&` 和 `*` 到处都是的根本原因。

## 那还要不要读讲义？

**要，但读法不一样。**

有基础的时候，讲义的用处不是"教我",而是两件事：

1. **划清边界**：哪些 C 的写法看起来和你熟悉的东西一样、其实不一样（就是上面那三条的完整版）
2. **提供最小的必要记忆**：每课结尾那个「最少必要记忆」列表，就是那一课真正需要背下来的东西，其余都是解释

所以快路的正确姿势是：**先看每课的「最少必要记忆」→ 写练习 → 卡住了再回头读正文那一节。**
