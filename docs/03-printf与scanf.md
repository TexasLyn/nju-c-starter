# 03 · printf 的精细控制、scanf 和 math.h

> **本课内容：math.h、浮点精度与格式输出**
> 这课的主题是**"怎么把数字按要求的格式打印出来"**。听起来简单，但这是练习和上机题里最容易丢分的地方——**答案算对了，格式不对，照样零分**。

---

## 1. 浮点数的第一个真相：它不精确

先看一个实验。在**任何**语言里算 `0.1 + 0.2`，你大概都会得到一个奇怪的答案：

```
0.30000000000000004
```

**C 里这个问题更明显**，因为 C 的 `float` 只有 4 个字节：

```c
float f = 0.1f;
printf("%.20f\n", f);    // 0.10000000149011611938
```

小数在计算机里是用二进制表示的，而 `0.1` 在二进制里是**无限循环小数**，只能存一个近似值。这跟你用十进制写 `1/3 = 0.3333...` 存不下是一个道理。

**这对你意味着什么？**

| 场景 | 后果 | 怎么处理 |
|---|---|---|
| 打印结果 | 一般看不出来 | 用 `%.6f` 限制小数位数，误差藏在后面看不见 |
| 判断相等 `a == b` | **会出错！** | 改成判断差的绝对值够小：`fabs(a-b) < 1e-6` |
| 多轮累加 | 误差会累积 | 尽量用 `double` 而不是 `float` |

### ⚠️ 浮点数不能用 `==` 比较

```c
double a = 0.1 + 0.2;
if (a == 0.3) {              // ✗ 这个条件永远不成立！
    printf("相等\n");
}

if (fabs(a - 0.3) < 1e-6) {  // ✓ 正确写法
    printf("相等\n");
}
```

`1e-6` 是**科学计数法**，意思是 1×10⁻⁶ = 0.000001。C 里 `1e-6`、`1.5e3`（=1500）、`2E-8` 都是合法的写法。

**记住这个套路：判断两个浮点数相等，永远写成 `fabs(a - b) < 一个很小的数`。** 上机题爱考，平时也常用。

## 2. 用 `double`，别用 `float`

这是给你的实用建议：**一律用 `double`。**

原因很简单：`double` 有 8 个字节，有效数字约 15～17 位；`float` 只有 4 个字节，有效数字约 7 位。练习里经常要精确到小数点后 6 位，用 `float` 误差会露出来。

```c
float  f = 3.14159265358979f;    // 只能存下约 3.1415927
double d = 3.14159265358979;     // 能存下 3.14159265358979
```

⚠️ 用 `float` 时，**字面量末尾的 `f` 不能漏**。写了 `float f = 3.14;` 编译器会警告你把 `double` 塞进 `float`（精度会丢）。加个 `f` 就没警告了。

## 3. printf 的完整格式：`%[宽度][.精度]类型`

这是本课的核心。`%` 和字母之间可以插两个数字，控制输出的样子：

```
%d              →  普通输出
%5d             →  宽度 5，不够的左边补空格
%-5d            →  宽度 5，左对齐（不够的右边补空格）
%.2f            →  保留 2 位小数
%8.2f           →  总宽 8，保留 2 位小数
%05d            →  宽度 5，不够的左边补 0
```

### 逐个看效果

```c
int n = 42;
double x = 3.14159;

printf("[%d]\n", n);        // [42]
printf("[%5d]\n", n);       // [   42]      右边顶到第 5 格
printf("[%-5d]\n", n);      // [42   ]      左边顶到第 1 格
printf("[%05d]\n", n);      // [00042]      补 0 不补空格

printf("[%f]\n", x);        // [3.141590]   默认 6 位小数
printf("[%.2f]\n", x);      // [3.14]
printf("[%.0f]\n", x);      // [3]          ← 会四舍五入，不是砍掉
printf("[%10.3f]\n", x);    // [     3.142]  总宽 10，3 位小数
```

**`%.2f` 会四舍五入**，不是截断。`printf("%.2f", 3.145)` 输出 `3.15`（实际上因为浮点误差可能是 `3.14`，这是正常的，别纠结）。

### ⚠️ 宽度不够会怎样

如果数字本身比指定的宽度还长，**宽度限制会被忽略**，数字原样打印：

```c
printf("[%3d]\n", 12345);   // [12345]   宽度 3 装不下，就撑破
```

### 对齐表格的用法

经常要输出表格。技巧是**先定好每列宽度，再统一用**：

```c
printf("%-10s%8s%8s\n", "姓名", "语文", "数学");
printf("%-10s%8d%8d\n", "小明", 95, 88);
printf("%-10s%8d%8d\n", "小红", 78, 92);
```

- `%-10s`：字符串左对齐，占 10 格（名字长短不一时能对齐）
- `%8d`：数字右对齐，占 8 格（数字右对齐看起来整齐）

**记这个口诀：文字左对齐用负号，数字右对齐不用负号。**

## 4. scanf 的用法

```c
int n;
double x;
char c;

scanf("%d", &n);         // 读一个整数
scanf("%lf", &x);        // 读一个 double（注意是 %lf！）
scanf("%c", &c);         // 读一个字符

scanf("%d %d", &a, &b);  // 一次读两个整数
```

### ⚠️ 三个必须记住的点

**① `double` 在 scanf 里必须用 `%lf`**

```c
double x;
scanf("%f", &x);      // ✗ 读不进来，x 还是垃圾值
scanf("%lf", &x);     // ✓
```

`printf` 用 `%f` 打 `double`，但 `scanf` 必须用 `%lf`。**这是唯一一处两边的格式符不一样**，也是最容易栽的坑。

**② 变量前面必须有 `&`**

```c
scanf("%d", &n);      // ✓
scanf("%d", n);       // ✗ 漏了 &
```

漏 `&` 可能让程序崩溃（`Segmentation fault`），也可能悄悄读进错的值。🔸 **原理第 8 课讲，现在先当铁律记住。**

例外：读字符串 `%s` 时不用写 `&`（因为数组名本身就是地址，第 10 课解释）。

**③ 输入之间的分隔符**

```c
scanf("%d %d", &a, &b);
```

`%d` 和 `%d` 之间的空格表示"**跳过任意多个空白字符**"（空格、Tab、回车都算）。所以下面这些输入**都能正确读入**：

```
3 4          ← 空格分隔
3    4       ← 多个空格
3
4            ← 换行分隔（你按回车后继续输入 4）
```

这是个好消息：**你不用担心用户用空格还是回车分隔，`%d` 自动跳过空白。**

### `%c` 的特殊坑

```c
int n;
char c;
scanf("%d", &n);
scanf("%c", &c);     // ⚠️ 这里会读到上一行残留的回车符！
```

因为 `%d` 读完数字后，**把回车符留在了输入缓冲里**。接着 `%c` 读的时候，第一个字符就是那个回车。

**解决办法**：在 `%c` 前面加一个空格——

```c
scanf(" %c", &c);    // ✓ 注意 %c 前面有个空格，意思是"跳过前面的空白"
```

🔸 这个坑第 12 课讲字符串时会详细解释「输入缓冲」是什么。现在先记住：**读字符时，`%c` 前面加个空格更安全。**

## 5. math.h：数学函数库

要算开方、三角函数、指数，得引入 `math.h`：

```c
#include <stdio.h>
#include <math.h>      // ← 多加这一行
```

### 常用函数

| 函数 | 作用 | 例子 | 结果 |
|---|---|---|---|
| `sqrt(x)` | 开平方 | `sqrt(16)` | `4.0` |
| `fabs(x)` | **浮点数**的绝对值 | `fabs(-3.5)` | `3.5` |
| `abs(x)` | **整数**的绝对值 | `abs(-3)` | `3` |
| `pow(x, y)` | x 的 y 次方 | `pow(2, 10)` | `1024.0` |
| `exp(x)` | e 的 x 次方 | `exp(1)` | `2.718282` |
| `log(x)` | 自然对数 ln(x) | `log(2.718281828)` | `1.0` |
| `log10(x)` | 以 10 为底的对数 | `log10(1000)` | `3.0` |
| `sin(x)` `cos(x)` `tan(x)` | 三角函数 | `sin(0)` | `0.0` |
| `fmod(x, y)` | 浮点数取余 | `fmod(7.5, 2)` | `1.5` |

### ⚠️ 两个大坑

**① 三角函数的角度单位是弧度，不是度**

```c
sin(30)             // ✗ 你以为在算 sin30°，其实在算 sin(30弧度)
sin(30 * PI / 180)  // ✓ 先把 30 度换成弧度
```

换算公式：**弧度 = 角度 × π / 180**

π 在 `math.h` 里**没有**定义（这是 C 语言的一个历史遗留问题），要自己定义：

```c
#define PI 3.14159265358979323846
```

🔸 `#define` 是宏定义，第 8 课细说。现在只要知道它能给一个常量起名字，写在使用它之前就行。

**② `fabs` 和 `abs` 别搞混**

```c
fabs(-3.5)     // 3.5   ← 用于 double
abs(-3)        // 3     ← 用于 int
```

用错了不会报错（因为 C 会做隐式转换），但结果可能不对。**记住：带 f 的那个是给浮点数用的**（f 就是 float 的意思）。

### 关于编译

有些环境（老的 Linux）编译用了 `math.h` 的程序要加 `-lm` 参数：

```bash
gcc math_test.c -o math_test -lm
```

**macOS 和 Windows 上的 MinGW 一般不需要**，直接编译就行。CLion 里也不用额外配置。但如果你以后在别的机器上编译报错说 `undefined reference to 'sqrt'`，就是缺 `-lm`。

## 6. 本课最少必要记忆

1. **`%.2f`** 保留 2 位小数，**`%8.2f`** 总宽 8 保留 2 位，**`%05d`** 补零
2. **`double` 在 scanf 里是 `%lf`**（多一个 l），printf 里还是 `%f`
3. **浮点数不能用 `==` 比较**，写成 `fabs(a-b) < 1e-6`
4. 用 `math.h` 要 `#include <math.h>`，**三角函数用弧度**，π 要自己定义
5. `fabs` 用于小数，`abs` 用于整数

## 7. 新手最常犯的 3 个错

**① scanf 里 `double` 用了 `%f`**

```c
double x;
scanf("%f", &x);     // ✗ x 读到的是垃圾值
scanf("%lf", &x);    // ✓
```

**这个坑特别隐蔽**：程序不报错，但 `x` 的值完全不对（通常是个极小的数或 0）。看到"输入的浮点数结果完全离谱"，第一反应就是查这个。

**② 三角函数用了角度**

```c
printf("%f\n", sin(30));              // 输出 -0.988032，完全不是 0.5
printf("%f\n", sin(30 * PI / 180));   // 输出 0.500000 ✓
```

**③ 忘了 `#include <math.h>`**

```c
#include <stdio.h>
int main(void) {
    printf("%f\n", sqrt(16.0));    // 报错：call to undeclared function 'sqrt'
}
```

现代 clang 编译器把"调用了没声明的函数"当**硬错误**处理（老编译器只给个警告，然后给你一个乱猜的结果）。所以漏 `math.h` 会直接编译失败。**报错信息里出现 `undeclared function`，八成是漏了某个 `#include`。**
