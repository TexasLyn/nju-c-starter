# 14 · 文件读写

> **本课内容：文件 I/O，编程题里经常要求的内容**
> 这一课**特别重要**，因为上机题里的编程题**都要求把结果写入文件**，而且文件名是固定的（`result.txt`）。学会了这一课，写文件类的题目就有底了。

---

## 1. 为什么要用文件

前面所有的程序，输出都打在屏幕上。**程序一结束，输出就没了。**

文件的作用是**把数据存下来**，下次还能用。

```
   之前：程序 → 屏幕 → 你看一眼 → 关掉就没了
   文件：程序 → 文件 → 磁盘上留着 → 下次还能读
```

**实际用途**：题目要求"把结果写入 `result.txt`"，判题时会去检查这个文件的内容。

---

## 2. 三步走：打开 → 读写 → 关闭

文件操作永远是这三步：

```c
#include <stdio.h>

FILE *fp;                                   /* ① 声明一个文件指针 */

fp = fopen("data.txt", "w");                /* ② 打开文件 */

if (fp == NULL) {                           /* ③ 检查是否成功 */
    printf("打开文件失败\n");
    return 1;
}

fprintf(fp, "hello\n");                     /* ④ 读写 */

fclose(fp);                                 /* ⑤ 关闭 */

return 0;
```

⚠️ **四件事必须做对**：

1. **`FILE *fp`** —— 声明文件指针（`FILE` 要大写，在 `stdio.h` 里定义）
2. **`fopen(文件名, 模式)`** —— 打开文件，返回文件指针
3. **检查 `fp == NULL`** —— 文件打不开时 fopen 返回 NULL
4. **`fclose(fp)`** —— 关闭文件，**必须做**

---

## 3. `fopen` 的模式

**模式字符串**决定了你怎么用这个文件：

| 模式 | 含义 | 文件不存在时 | 文件已存在时 |
|---|---|---|---|
| `"r"` | 只读 | **失败**，返回 NULL | 从头开始读 |
| `"w"` | 只写 | 创建新文件 | **清空原内容！** |
| `"a"` | 追加写 | 创建新文件 | 在末尾接着写 |
| `"r+"` | 读写 | 失败 | 从头读写 |
| `"w+"` | 读写 | 创建 | **清空** |
| `"a+"` | 读写追加 | 创建 | 末尾读写 |

⚠️ **`"w"` 会清空文件！** 这是最容易造成"数据丢失"的坑。如果你想保留原内容再添加，要用 `"a"`。

🔸 **上机题最常用的是 `"r"`（读输入数据）和 `"w"`（写结果）。**

### ⚠️ 文件路径

```c
fopen("data.txt", "w");                     /* 相对路径：当前工作目录 */
fopen("~/data.txt", "w");        /* 绝对路径 */
fopen("C:\\test\\data.txt", "w");           /* Windows 路径：反斜杠要写两个！ */
```

**在 CLion 里运行程序时，"当前工作目录"是哪里？**

- **CLion 默认是项目的 build 目录**（比如 `cmake-build-debug/`），**不是源代码所在的目录**
- 所以 `fopen("out.txt", "w")` 生成的文件可能在 `cmake-build-debug/out.txt`

🔸 **想在源代码目录看到文件？** 在 CLion 的运行配置里改 Working directory。或者干脆用绝对路径：

```c
fopen("out.txt", "w");
```

**练习和上机题里**：题目说"写入 out.txt"就写相对路径 `"out.txt"`，判题程序会在它自己的工作目录里找。

## 4. 写文件：`fprintf` 和 `fputs`

```c
FILE *fp = fopen("out.txt", "w");

/* fprintf —— 和 printf 一模一样，只是多一个文件指针参数放在最前面 */
fprintf(fp, "%d %s\n", 42, "hello");

/* fputs —— 输出一个字符串（不加换行） */
fputs("一行文字\n", fp);

/* fputc —— 输出一个字符 */
fputc('A', fp);

fclose(fp);
```

🔸 **`fprintf` 就是加了第一个参数的 `printf`**：

```c
printf("%d\n", x);              /* 输出到屏幕 */
fprintf(fp, "%d\n", x);         /* 输出到文件 fp */
```

格式符完全一样（`%d` `%f` `%s` `%c` …）。**你已经会的 printf 知识全部通用。**

### 文件里有什么

如果执行 `fprintf(fp, "%d %s\n", 42, "hello");`，`out.txt` 的内容是：

```
42 hello
```

**就是一个普通的文本文件**，用文本编辑器打开就能看。**这一点很重要**：判题时就是这样检查你的结果对不对。

## 5. 读文件：`fscanf` 和 `fgets`

```c
FILE *fp = fopen("in.txt", "r");

if (fp == NULL) { ... }

int n;
double x;
char s[100];

/* fscanf —— 和 scanf 一模一样，多一个文件指针参数 */
fscanf(fp, "%d", &n);
fscanf(fp, "%lf", &x);

/* fgets —— 从文件读一行，和从键盘读的用法一样 */
fgets(s, 100, fp);

fclose(fp);
```

### ⚠️ 怎么判断读到文件末尾了

`fscanf` 有返回值，**返回成功读到的项数**：

```c
while (fscanf(fp, "%d", &n) == 1) {         /* 成功读到 1 个数就继续 */
    printf("%d\n", n);
}
```

**这是读文件的标准写法。** 文件读完了 `fscanf` 会返回 `EOF`（一个特殊值，通常是 -1），循环就退出了。

`fgets` 则在读不到时返回 `NULL`：

```c
char line[200];
while (fgets(line, 200, fp) != NULL) {
    printf("%s", line);
}
```

### 读文件的三条铁律

1. **先检查 `fp == NULL`**（文件可能不存在）
2. **`"r"` 模式下文件不存在会失败**，不像 `"w"` 会自动创建
3. **读之前先想清楚文件的格式**（几个数一行？用空格还是逗号分隔？）

## 6. 编程练习的固定套路（务必背熟）

上机题里的编程题**都要求写文件**，而且文件名有固定要求：

| 项目 | 要求 |
|---|---|
| 程序文件名 | **`solution.c`**（有时是 `solution2.c`） |
| 结果文件（写） | **`result.txt`**（读入是 `input.txt`） |
| 另一套 | 结果文件 `output.txt` |

**这意味着：程序最后必须有一段写文件的代码，用固定的文件名。**

### 上机题的典型结构

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <math.h>

/* 你的辅助函数（素数判断、排序等等） */

int main(void)
{
    /* 第一步：从 input.txt 读入数据（有的题目要求，有的直接输入） */
    FILE *fin = fopen("input.txt", "r");
    if (fin != NULL) {
        /* 读数据 */
        fclose(fin);
    }

    /* 第二步：计算 */

    /* 第三步：把结果写入 result.txt —— 这一步是上机题要求，必须有 */
    FILE *fout = fopen("result.txt", "w");
    if (fout == NULL) {
        return 1;
    }

    fprintf(fout, "%d\n", answer);          /* 按题目要求的格式写 */

    fclose(fout);

    return 0;
}
```

🔸 **`fclose(fout)` 千万别忘。** 忘了的话，缓冲区里的数据可能还没真正写进磁盘，判题时看到的就是空文件或者不完整的内容。

**（严格说，程序正常 return 时操作系统会帮你关闭所有文件并刷新缓冲区。但上机题里养成显式 fclose 的习惯绝对没错。）**

### 从典型上机题里看到的真实要求

典型的编程题长这样：

> 编写函数 `int rev_prime(int m, int n, int x[])`，
> 求出 [m, n] 区间内所有的"反序素数"（本身是素数，反序后也是素数），
> 存入数组 x，返回个数。
> **把结果用 fprintf 写入文件 out.txt。**

**注意**：题目既要求函数返回值，**又要求写文件**。这两件事是分开的。

## 7. 完整例子：把素数的平方写入文件

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("squares.txt", "w");

    if (fp == NULL) {
        printf("无法创建文件\n");
        return 1;
    }

    for (int i = 1; i <= 10; i++) {
        fprintf(fp, "%d %d\n", i, i * i);
    }

    fclose(fp);

    printf("已写入 squares.txt\n");
    return 0;
}
```

**生成的 `squares.txt` 内容**：

```
1 1
2 4
3 9
...
10 100
```

### 读回来

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("squares.txt", "r");
    int a, b;

    if (fp == NULL) {
        printf("文件不存在\n");
        return 1;
    }

    while (fscanf(fp, "%d %d", &a, &b) == 2) {       /* 每次读两个数 */
        printf("%d 的平方是 %d\n", a, b);
    }

    fclose(fp);
    return 0;
}
```

⚠️ **`fscanf(fp, "%d %d", &a, &b) == 2`** 里的 2 是"成功读到了 2 项"的意思。**这个数字必须和你格式串里的项数一致。**

## 8. 本课最少必要记忆

1. **三步走**：`fopen` → 读写 → `fclose`
2. **`fopen` 后必须检查 `fp == NULL`**
3. **`fprintf(fp, ...)` 就是多一个参数的 `printf`**
4. **`"w"` 会清空文件**，`"a"` 是追加
5. **上机练习必须写文件**，文件名 `result.txt`，且**别忘 `fclose`**

## 9. 新手最常犯的 3 个错

**① 忘了检查 `fopen` 的返回值**

```c
FILE *fp = fopen("in.txt", "r");
int n;
fscanf(fp, "%d", &n);        /* ✗ 如果文件不存在，fp 是 NULL，这行直接崩溃 */
```

**症状**：`Segmentation fault: 11`。**看到读文件时崩溃，第一反应就是检查 fopen 的返回值。**

**② 忘了 `fclose`**

```c
FILE *fp = fopen("out.txt", "w");
fprintf(fp, "%d\n", 42);
/* ✗ 没有 fclose，数据可能还在缓冲区里没写入磁盘 */
```

**症状**：程序"看起来成功了"，但打开文件是空的。

**③ 模式用错，把数据清空了**

```c
FILE *fp = fopen("important.txt", "w");     /* ✗ 如果本意是追加，这会清空原文件 */
FILE *fp = fopen("important.txt", "a");     /* ✓ 追加 */
```

**这个错误的后果是不可逆的**——文件内容一旦被清空就找不回来了。写代码前想清楚：我是要覆盖还是追加？
