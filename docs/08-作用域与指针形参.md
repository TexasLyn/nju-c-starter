# 08 · 作用域、预处理与指针形参

> **本课内容：变量作用域、存储类别、预处理、指针形参**
> 这一课有两条线：**`#define` 宏**（上机题填空必考）和**指针作为函数参数**（终于要解释 `&` 了）。指针是 C 最核心也最容易慌的部分，我会从"为什么需要它"讲起。

## 1. 变量的作用域：花括号圈定范围

**作用域**就是一个变量"活着"的范围。规则很简单：

> **变量从它被声明的那一行开始，到它所在的最近一层花括号结束为止，都有效。**

```c
int main(void)
{
    int a = 1;              /* a 在整个 main 里有效 */

    if (a > 0) {
        int b = 2;          /* b 只在这个 if 的花括号里有效 */
        printf("%d\n", a);  /* ✓ a 在外面定义的，能用 */
        printf("%d\n", b);  /* ✓ b 在作用域内 */
    }

    printf("%d\n", a);      /* ✓ */
    printf("%d\n", b);      /* ✗ 编译错误：b 已经不存在了 */
}
```

报错信息是：

```
error: use of undeclared identifier 'b'
```

**看到 `undeclared identifier`，第一反应就是"这个变量是不是在别的花括号里定义的？"**

### 🔸 内外同名：里面的会"遮蔽"外面的

```c
int main(void)
{
    int x = 10;

    {
        int x = 20;                 /* 新的 x，遮蔽了外面的 x */
        printf("%d\n", x);          /* 输出 20 */
    }

    printf("%d\n", x);              /* 输出 10，外面的 x 没变 */
}
```

**这是上机题"阅读程序题"的经典题型。** 记住规则：**内层的 x 是另一个变量，和外层毫无关系。** 内层花括号一结束，外面的 x 就"重新出现"了。

```
    main 的 x             花括号里的 x
    ┌───────┐
    │  10   │             ┌───────┐
    └───────┘             │  20   │
         ↑                └───────┘
      一直存在              花括号结束就消失
```

**⚠️ 上机题陷阱**：如果内层是 `x = 20;`（没有 `int`），那就是**修改外面的 x**，不是新建变量：

```c
int x = 10;
{
    x = 20;              /* ← 没有 int，改的就是外面的 x */
}
printf("%d\n", x);       /* 输出 20！ */
```

**有没有 `int` 决定了是"新建一个"还是"改原来那个"。** 这是最容易看错的地方，读程序题时要瞪大眼睛看变量声明处有没有类型名。

## 2. `#define` 宏：文本替换

`#define` 是**预处理指令**，做的是最粗暴的一件事：**文本替换**。在编译之前，预处理器把代码里所有出现宏名的地方，原样替换成宏的内容。

```c
#define PI 3.14159
#define MAXN 100

int main(void)
{
    double r = 2.0;
    double area = PI * r * r;      /* 编译前变成 3.14159 * r * r */
    int a[MAXN];                    /* 编译前变成 int a[100]; */
    return 0;
}
```

⚠️ **`#define` 后面没有分号！** 写了分号，分号也会被替换进去：

```c
#define PI 3.14159;             /* ✗ 多了分号 */
double area = PI * r * r;       /* 变成 3.14159; * r * r; → 语法错误 */
```

### 🔸 宏的本质：它就是一个查找替换

**这一点极其重要，是宏所有"坑"的来源。** `#define` 不是变量，没有类型，不占内存。它只是"看到这个单词就换成那串字符"。

### ⚠️ 宏最经典的坑：不加括号

```c
#define N 3 + 1

printf("%d\n", N * 2);      /* 你以为是 (3+1)*2 = 8 */
                            /* 实际是 3 + 1*2 = 5    ✗ */
```

**因为它是纯文本替换**，`N * 2` 变成了 `3 + 1 * 2`，乘法优先，所以是 5。

**正确做法是给宏加括号**：

```c
#define N (3 + 1)

printf("%d\n", N * 2);      /* 变成 (3+1)*2 = 8  ✓ */
```

### ⚠️ 连锁替换的坑（上机题必考）

```c
#define M 3
#define N M + 1

printf("%d\n", M * N);
```

**一步一步展开**（替换是反复进行的）：

```
M * N
→ 3 * N                  （M 换成 3）
→ 3 * M + 1              （N 换成 M + 1）
→ 3 * 3 + 1              （M 又换成 3，因为替换会再来一轮）
→ 10                     （先算乘法，3*3+1）
```

**答案是 10，不是 12。**

⚠️ **注意 `N` 定义时用的是 `M`，而不是 `M` 的值。** 宏不会"记住"当时的 M 是多少，替换完再继续找有没有可以替换的。这就是"文本替换"和"变量赋值"的根本区别。

**如果定义时加了括号就不一样了**：

```c
#define M 3
#define N (M + 1)

printf("%d\n", M * N);      /* 3 * (M+1) → 3 * (3+1) = 12 */
```

### 🔸 另一个坑：宏名出现在意想不到的地方

```c
#define a 5
#define sub a

double y = sin(sub);        /* 替换成 sin(5)，不是 sin(a) */
```

⚠️ **我自己试过这个例子**：如果写成 `sizeof(sin(sub))` 而 `a` 没定义，会编译报错 `use of undeclared identifier 'a'`。因为 `sub` 被换成 `a`，但 `a` 在这里不是宏名（在 `#define sub a` 里，`a` 是替换内容，不是要替换的目标），所以它就是普通标识符，而普通标识符 `a` 没定义过。

**这个例子说明**：宏替换是**单向**的、**不分上下文**的。`#define sub a` 只保证"代码里写 `sub` 的地方变成 `a`"，不保证 `a` 本身有定义。

### 宏 vs 常量变量

| 用 `#define` | 用 `const` 变量 |
|---|---|
| 文本替换，无类型 | 有类型，编译器会检查 |
| 不占内存 | 占内存 |
| 调试时看不到名字 | 调试时能看到 |
| 经典教材里的主流写法 | 现代代码更推荐 |

**经典教材和上机题都用 `#define`**，你跟着用就行。

## 3. 条件编译：`#ifdef`

```c
#define DEBUG

int main(void)
{
#ifdef DEBUG
    printf("调试信息：程序开始\n");
#endif

    printf("正常输出\n");
    return 0;
}
```

**`#ifdef X` 的意思是"如果 X 被定义过"**，它后面到 `#endif` 之间的代码才会被编译进去。如果没定义，那段代码等于不存在。

| 指令 | 含义 |
|---|---|
| `#ifdef X` | 如果定义了 X |
| `#ifndef X` | 如果没有定义 X |
| `#else` | 否则 |
| `#endif` | 结束（**必须有**） |

### 常见用途：防止头文件重复包含

```c
#ifndef MY_HEADER_H
#define MY_HEADER_H

/* 头文件内容写在这里 */

#endif
```

这几乎是每个头文件的标准开头。第 13 课多文件时会细讲。

### ⚠️ `#ifdef` 的坑：删掉 `#define` 之后

```c
/* #define DEBUG */          /* ← 注释掉了 */

#ifdef DEBUG
    printf("调试信息\n");     /* 这行不会被编译 */
#endif
```

⚠️ **注意 `#ifdef` 检查的是"这个宏名有没有被定义过"，不是"它的值是多少"。**

```c
#define DEBUG 0              /* 定义了，值是 0 */

#ifdef DEBUG
    printf("这行会被编译！\n");   /* ✗ 你以为值是 0 就不编译，错！
                                    #ifdef 只看"有没有定义" */
#endif

#if DEBUG                    /* ✓ 这个才看值，0 就不编译 */
    printf("这行不会被编译\n");
#endif
```

**`#ifdef` 看"有没有"，`#if` 看"值是多少"。** 这是上机题爱考的区别。

## 4. 存储类别：`auto`、`static`、`extern`

**存储类别**决定变量的三件事：**存活多久**、**存在哪**、**谁能看见**。

### 局部变量默认是 `auto`（自动变量）

```c
void f(void)
{
    int x = 1;          /* 等价于 auto int x = 1; */
}
```

`auto` 是默认的，**从来不写**。它的特点是：**函数一返回，变量就消失**，下次调用重新开始。

### `static` 局部变量：函数退出后还活着

```c
void counter(void)
{
    static int n = 0;       /* ← 注意这个 static */
    n++;
    printf("%d\n", n);
}

int main(void)
{
    counter();      /* 1 */
    counter();      /* 2 */
    counter();      /* 3 */
    return 0;
}
```

**对比一下没有 `static` 的情况：**

```c
void counter(void)
{
    int n = 0;              /* 没 static */
    n++;
    printf("%d\n", n);
}
/* 调用三次，每次都输出 1，因为每次进来都重新初始化 */
```

🔸 **`static` 局部变量的两个特点**：

1. **只初始化一次**。`static int n = 0;` 只在第一次进入函数时执行，之后每次调用都跳过这句话。
2. **函数返回后依然存在**，值保留到下次调用。

**用在哪？** 计数、缓存、只需要算一次的东西。

```c
/* 保证初始化只做一次 */
void init(void)
{
    static int inited = 0;
    if (inited) return;
    /* ... 真正的初始化代码 ... */
    inited = 1;
}
```

### `static` 全局变量：只在本文档可见

```c
static int counter = 0;      /* 写在所有函数外面 */
```

这个 `static` 的意思和上面不一样：**它表示"这个变量只在本文件里能用"**，别的文件看不到它。这叫**内部链接**。

第 13 课多文件时会用到。现在知道有这回事就行。

### `extern`：声明"别的地方有这个变量"

```c
extern int global_count;     /* 不分配内存，只是说"别处有个叫这个名字的" */
```

用于跨文件共享变量。单文件程序基本用不到。

### 一张表总结

| 写法 | 存活时间 | 可见范围 | 典型用途 |
|---|---|---|---|
| `int x;`（函数内） | 函数执行期间 | 本函数 | 普通局部变量 |
| `static int x;`（函数内） | **整个程序运行期间** | 本函数 | 计数、缓存 |
| `int x;`（函数外） | 整个程序运行期间 | **所有文件** | 全局变量 |
| `static int x;`（函数外） | 整个程序运行期间 | **仅本文件** | 文件私有全局变量 |
| `extern int x;` | 不分配内存 | 看定义处 | 跨文件引用 |

## 5. 全局变量

写在所有函数外面的变量叫**全局变量**，任何函数都能读写它。

```c
#include <stdio.h>

int count = 0;              /* 全局变量，任何函数都能用 */

void add(void)
{
    count++;                /* 直接改，不需要传参 */
}

int main(void)
{
    add();
    add();
    printf("%d\n", count);  /* 2 */
    return 0;
}
```

**全局变量的特点**：

- 所有函数都能访问，**不用传参**
- **自动初始化为 0**（局部变量不初始化是垃圾值，全局变量是 0）
- 整个程序运行期间都存在

### ⚠️ 为什么"用全局变量偷懒"是坏习惯

```c
int a, b, result;           /* ✗ 三个全局变量 */

void compute(void) { result = a + b; }

int main(void) {
    a = 3; b = 5;
    compute();
    printf("%d\n", result);
}
```

看起来省事，但：

1. **任何函数都能改它们**，出问题时你要翻遍所有函数找谁改的
2. **函数不再自包含**，`compute()` 依赖外面的 `a`、`b`，不能单独理解和测试
3. **改名/重构困难**，牵一发动全身

🔸 **原则：能用参数和返回值就用，全局变量只在"确实需要跨函数共享状态"时才用。**

**但有些题目会要求用全局变量**（比如第 9 课的复数运算，题目明确说"结果存全局变量"），那时候照着做就行。

## 6. ⚠️ 指针：终于要解释 `&` 了

前面几课我都让你"先记住 `scanf` 要写 `&`"。现在解释为什么。

### 内存就像一排带门牌号的格子

```
   地址:  1000  1001  1002  1003  1004 ...
         ┌─────┬─────┬─────┬─────┬─────┐
         │     │  5  │     │     │     │ ...
         └─────┴─────┴─────┴─────┴─────┘
                  ↑
             变量 x 住在这里，门牌号是 1001
```

**每个变量都住在内存的某个位置，那个位置的编号叫"地址"。**

### `&` 和 `*`

| 符号 | 名字 | 作用 |
|---|---|---|
| `&x` | 取地址 | 得到变量 x 的地址（门牌号） |
| `*p` | 解引用 | 得到指针 p 指向的那个变量的值 |

```c
int x = 5;
int *p = &x;            /* p 里存的是 x 的地址 */

printf("%d\n", x);      /* 5       ← 直接读 x */
printf("%d\n", *p);     /* 5       ← 通过地址读 x */
```

**声明 `int *p` 时那个 `*` 表示"p 是一个指针"，不是解引用。** 这是 C 语法的一个历史遗留问题，同一个符号在不同位置意思不同：

```c
int *p;             /* 这里的 * 是"声明指针" */
*p = 10;            /* 这里的 * 是"解引用" */
```

🔸 **怎么分？看位置**：在类型后面的（`int *p`）是声明，在表达式里的（`*p = 10`）是解引用。

### 为什么 `scanf` 需要 `&`

```c
int x;
scanf("%d", &x);
```

`scanf` 的任务是**把从键盘读到的数字写进变量 x**。它是另一个函数，直接传 `x` 的话只传了值（拷贝），它改的是副本，你的 `x` 不会变（这就是第 7 课讲的"值传递"）。

所以必须**把 x 的地址告诉它**，它才能顺着地址找到你的 x 并往里写。

```
   你的 x                      scanf 内部
   ┌──────┐
   │  ??  │  ← 地址 1001
   └──────┘
      ↑
      └── &x 传的是 1001，scanf 顺着 1001 找到这个格子，把读到的数填进去
```

🔸 **一句话记住**：`&x` 是"告诉函数 x 住在哪"，函数才能去改它。

## 7. 指针作为函数参数：让函数能改外面的变量

这是指针最实用的地方，也是本课的核心。

```c
/* ✗ 这样写，外面的变量改不了 */
void bad_inc(int n)
{
    n = n + 1;
}

/* ✓ 用指针，就能改 */
void good_inc(int *p)
{
    *p = *p + 1;            /* 顺着地址找到那个变量，把它加 1 */
}

int main(void)
{
    int a = 5;

    bad_inc(a);
    printf("%d\n", a);      /* 5，没变 */

    good_inc(&a);           /* 传地址 */
    printf("%d\n", a);      /* 6，变了 */

    return 0;
}
```

**对比一下**：

| | 传值 `void f(int n)` | 传指针 `void f(int *p)` |
|---|---|---|
| 调用时 | `f(a)` | `f(&a)` |
| 函数里用 | 直接用 `n` | 用 `*p` |
| 能改外面的 a 吗 | **不能** | **能** |
| 什么时候用 | 只需要读 | 需要写回结果 |

### 🔸 为什么有的函数要用指针参数

看这个需求：**写一个函数，同时返回两个结果**（比如求最大值的**位置**和**值**）。

C 的函数只能 `return` 一个值。怎么办？**一个用返回值，其余的用指针参数带出来。**

```c
int find_max(int a[], int n, int *pos)
{
    int max = a[0];
    *pos = 0;

    for (int i = 1; i < n; i++) {
        if (a[i] > max) {
            max = a[i];
            *pos = i;           /* 把位置写到调用者的变量里 */
        }
    }

    return max;                 /* 值用返回值 */
}

int main(void)
{
    int a[5] = {3, 9, 2, 7, 5};
    int where;

    int mx = find_max(a, 5, &where);    /* 传 where 的地址 */
    printf("最大值 %d 在下标 %d\n", mx, where);     /* 最大值 9 在下标 1 */

    return 0;
}
```

🔸 **这个模式叫"输出参数"**，实际代码里非常常见。看到函数参数里有 `int *` 或 `long *`，基本就是要往里写结果的。

**注意这类题目的函数签名**，比如第 8 课的：

```c
int fun(long n, long *hw)
```

这告诉我们：函数返回 `int`（变换次数），另外通过 `*hw` 带出回文数结果。

## 8. 本课最少必要记忆

1. **作用域**：变量从声明处到最近的花括号结束。内层同名变量遮蔽外层
2. **`#define` 是纯文本替换**，不加括号会算错（`#define N 3+1` 时 `N*2` 得 5）
3. **`#ifdef` 只看"有没有定义"**，不看值是多少
4. **`static` 局部变量**：只初始化一次，函数返回后值还在
5. **`&x` 取地址，`*p` 取值**；传指针才能让函数修改外面的变量

## 9. 新手最常犯的 3 个错

**① 宏不加括号**

```c
#define N 3 + 1
int a = N * 2;          /* ✗ 得 5，不是 8 */
#define N (3 + 1)
int a = N * 2;          /* ✓ 得 8 */
```

**② 以为 `#define DEBUG 0` 会让 `#ifdef DEBUG` 不成立**

```c
#define DEBUG 0
#ifdef DEBUG
    /* ✗ 这段还是会被编译！因为 DEBUG 被定义过了 */
#endif
```

**③ 用指针参数时忘了 `&`**

```c
void inc(int *p) { (*p)++; }

int a = 5;
inc(a);         /* ✗ 编译错误：传 int 给 int*，类型不匹配 */
inc(&a);        /* ✓ */
```

**好消息**：指针类型不匹配是**编译错误**，不会悄悄出错。这比第 2 课那些"不报错但答案错"的坑友好多了。

反过来要注意的是**反过来用错**：

```c
int *p = &x;
printf("%d\n", p);      /* ✗ 打印的是地址（一串大数字），不是值 */
printf("%d\n", *p);     /* ✓ */
```
