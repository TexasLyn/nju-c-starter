# 开始之前：选一条路

> 这一步只花两分钟，但它决定了你接下来会不会在环境上卡住。

---

## 先回答一个问题：你有电脑吗？

### 没有 / 不想装任何东西 / 就想现在开始

→ **走 A 线：[在线编译器](A-零安装-在线编译器.md)**

打开一个网页就能写 C、能运行。5 分钟开始学第一课，一行都不用装。

**适合**：平板上学、公司/学校电脑不让装软件、先试试水看喜不喜欢。

**代价**：没法用本仓库的自动评测脚本（要手动对比输出），文件读写那一课（第 14 课）做不了。

---

### 有电脑，想装好环境长期学

→ **走 B 线（Windows）或 C 线（macOS）**

装好之后你能用本仓库的全部功能：CLion 里一键运行、`python3 tests/check.py` 自动判题、第 14 课的文件读写也能练。

| 你的系统 | 去哪 |
|---|---|
| Windows 10 / 11 | [B-Windows 本机安装](B-Windows本机安装.md) |
| macOS | [C-macOS 本机安装](C-macOS本机安装.md) |
| Linux | 你已经不需要教程了，装个 gcc 就行（`sudo apt install build-essential`） |

---

## 还想让 AI 陪你学？

装好环境之后（或者走 A 线的时候），可以看：

→ **[D-让 AI 当你的助教](D-让AI当你的助教.md)**

里面有写好的提示词，复制粘贴给你的 AI 助手（ChatGPT / Claude / 豆包 / ZCode 之类），它就知道怎么配合这套教材教你——**会提问引导，而不是直接把答案给你**。

## 三档难度对照

不确定自己属于哪一档？看这张表：

| 档位 | 你的情况 | 推荐 |
|---|---|---|
| **完全小白** | 没装过任何开发工具，不知道"终端"是什么 | [A 在线编译器](A-零安装-在线编译器.md)，先学两周再考虑装环境 |
| **会用电脑** | 装过软件、会复制粘贴命令、见过命令行 | [B Windows](B-Windows本机安装.md) 或 [C macOS](C-macOS本机安装.md)，照着走，每步都有截图式的说明 |
| **有基础** | 用过 VS Code / PyCharm / 终端，甚至用过 Cursor 这类 AI 编辑器 | [D 让 AI 当助教](D-让AI当你的助教.md) 里有一条"让 AI 自己装"的提示词，把下面这句话丢给它就行 |

**有基础的人可以偷懒**：把这段话复制给能操作你电脑的 AI（Cursor、ZCode、Claude Code 等）：

> 我在 `/path/to/c-starter` 这个目录里有一套 C 语言自学材料（有自己的 CMakeLists.txt 和 tests/check.py 评测脚本）。请帮我：
> 1. 检查我的电脑上有没有可用的 C 编译器（clang 或 gcc），没有就告诉我怎么装
> 2. 确认 `python3 tests/check.py --dir answers` 能跑通（应该 75 题全绿）
> 3. 如果哪一步失败，把原因和修法讲清楚
>
> 我的系统是：<这里写你的系统>

## 装完之后怎么验证成功了

不管走哪条线，最后都应该能看到这个：

```bash
cd c-starter
python3 tests/check.py --dir answers
```

输出结尾是：

```
结果：通过 75
```

**看到这一行，环境就通了。** 然后回去读 [00 · 怎么用这套材料](../docs/00-怎么用这套材料.md)。
